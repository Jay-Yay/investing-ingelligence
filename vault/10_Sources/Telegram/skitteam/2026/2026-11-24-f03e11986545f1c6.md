DELL Technologies FY3Q27 컨퍼런스콜

▶️ 주요 코멘트

FY3Q27 Revenue $54.9B — +103% YoY / EPS +265%:
Revenue $54.9B(+103%), Non-GAAP EPS $9.45(+265%). ISG가 Revenue의 68%, Operating Income의 83%까지 확대되며 Dell의 이익 중심이 Infrastructure로 빠르게 이동.

AI Server — Orders $60.2B / Revenue $22B / Backlog $132.3B:
Q3 AI Server Orders $60.2B, Revenue $22B, Backlog $132.3B 기록. 최근 4개 분기 AI Orders는 $180B, 신규 Order의 과반은 Vera Rubin NVL72 기반.

Backlog Quality — Capital·Land·Power까지 검증:
모든 AI Order에 대해 Customer Credit, End-customer Contract, Capital 조달 능력, Land·Power 확보 여부를 검증. Production 투입 전에도 재검토하는 구조로 Backlog Conversion에 높은 자신감 유지.

Demand > Supply — CY27에는 Gap 추가 확대 전망:
Management는 AI Infrastructure Demand 둔화 징후가 없으며 CY27에는 Demand가 Supply보다 더 크게 앞설 것으로 전망. Component Supply가 FY28 성장의 주요 제약 변수.

Traditional Servers $15B — +235% YoY:
Traditional Server & Networking Revenue $15B(+235%). 일반 Workload Refresh뿐 아니라 Inference·Agentic AI용 CPU Compute가 가장 빠르게 성장하는 신규 수요로 부상.

Agentic AI → CPU Server TAM 확대:
Agent Orchestration·Container·Sandbox·I/O 관리 등 Harness 작업은 CPU 중심. Agentic/Inference용 Server는 Traditional Server TAM의 약 20% 수준이며 ASP는 일반 Enterprise Server 대비 약 2배.

Memory·NAND — 2027에도 공급 부족·가격 상승 지속 전망:
Dell은 Enterprise DRAM·NAND에서 가격 하락 징후가 없다고 평가. HBM으로 DRAM Wafer Capacity가 이동하면서 Conventional Memory Supply가 제약돼 2027년에도 Inflationary Environment 지속 전망.

Storage — AI가 신규 수요 확대:
Storage Revenue $4.9B(+24%). Agentic AI의 KV Cache·Context Layer·Agent State·Logs·Artifacts가 신규 Storage Demand를 생성하며 AI Deal 내 Storage Attach도 상승.

FY27 Guidance 상향:
FY27 Revenue $202B(+약 80%), AI Server Revenue $78B, Non-GAAP EPS $29.68(+약 190%) 전망. Q4 AI Server Revenue도 약 $23.5B로 추가 성장 예상.

핵심 — GPU Server → CPU·Memory·Storage까지 AI Infrastructure 수요 확산:
AI Demand가 Training에서 Inference → Agentic → Recursive Learning으로 확대되며 GPU뿐 아니라 CPU Server·DRAM·NAND·Storage까지 Content 증가. Dell은 FY28에도 수요보다 Supply 확보가 더 중요한 변수라는 판단

▶️ 주요 Q&A

Q: AI CapEx Peak 우려와 달리 Demand > Supply라고 보는 이유는?
A: 최근 4개 분기 Orders $180B, 5-quarter Pipeline도 계속 증가. Dell AI Factory Customer는 최근 3개 분기에 4,500개 증가, 현재 Pipeline 내 고객 수도 누적 서비스 고객보다 많아 Demand Broadening 지속.

Q: Data Center 건설 지연 시 $132.3B Backlog 위험은?
A: 현재 Customer Reschedule 없음. Backlog는 Multi-quarter이며 약 100개 글로벌 Site에 분산. Dell은 Land·Power·Cooling·Financing을 수주 및 생산 전 각각 확인해 Conversion Risk를 관리.

Q: Traditional Server +235%는 가격 때문인가 Unit 때문인가?
A: Unit은 오히려 감소. 대신 Server당 Core·DRAM Bit·Storage Byte Content가 크게 증가. 최신 18G Server 1대가 구형 14G Server 12~14대를 대체할 정도로 고사양화 진행.

Q: Agentic AI가 CPU Server에 실제로 얼마나 중요한가?
A: 현재 Traditional Server 내 가장 빠르게 성장하는 영역. Financial Services·EDA·Semiconductor·HFT·Pharma 등 AI 선도 고객에서 수요 확대 중이며 향후 Recursive Learning이 추가 성장축.

Q: Vera Rubin 전환 시 Dell Margin은?
A: AI Server 자체는 기존 Mid-single-digit Margin 구조 유지. 다만 Rubin Rack에 Networking·Storage·Services Attach가 확대될수록 전체 Solution Margin 개선 가능.

Q: DRAM·NAND 가격이 안정되면 Server 수요가 더 좋아질까?
A: 회사는 당장 가격 하락 자체를 예상하지 않음. HBM Capacity 확대 → 일반 DRAM Supply 제약으로 2027에도 가격 상승 지속 전망. 현재 Server 고객도 가격 때문에 구매를 중단하기보다 더 고성능 시스템으로 Consolidation 중.

Q: ISG Margin은 AI Server Mix 확대에도 유지 가능한가?
A: Revenue와 OpEx를 Decouple하는 Operating Leverage가 구조적이라는 설명. FY27 동안 AI Server Revenue가 3배 이상 확대됐음에도 Full-year Operating Margin은 약 +350bp 개선 전망.
