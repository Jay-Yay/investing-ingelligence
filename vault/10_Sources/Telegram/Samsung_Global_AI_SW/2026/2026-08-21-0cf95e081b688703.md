중국계 추정 스텔스 모델 ‘Ox Alpha’ 등장

: OpenCode와 OpenRouter를 통해 미공개 Ox Alpha 모델 등장. 1M 컨텍스트와 멀티모달을 지원하며 코딩, 장시간 에이전트 작업 및 프로덕션 워크로드에 특화

: OpenCode는 1주일 무료 제공과 Zero Data Retention, 하루 100조 토큰 처리 용량을 제시

: 초기 성능도 주목. Ben Davis의 DeepSWE 10개 태스크 테스트에서 8개를 해결하며 강한 코딩, 에이전트 성능을 보임. 다만 전체 벤치마크가 아닌 소규모 샘플인 만큼 추가 검증 필요

: 개발사는 미공개지만 현재는 중국 프런티어 모델일 가능성이 상대적으로 높게 거론

: 기술적 특징 측면에서 tokenizer와 비디오 인코더 유사성, 출력 스타일과 오디오 입력을 거부하는 방식에서도 유사 패턴이 관찰된 Z AI의 GLM 계열이 주요 후보

: 샤오미 MiMo 역시 과거 Hunter Alpha를 OpenRouter에서 익명 테스트한 전례가 있어 주요 후보 중 하나

: 바이트댄스와 미니맥스도 모델 개발 역량과 대규모 추론 인프라 측면에서 가능한 후보지만 현재 Ox Alpha와 직접 연결되는 기술적 정황은 부족

: 미국 모델 가능성도 완전히 배제하기는 어려움. 특히 일리야 수츠케버의 SSI는 8월 첫 모델을 공개할 가능성이 언급된 타이밍

: 특히 100T tokens/day를 실제로 처리할 수 있다면 상당한 추론 인프라를 확보한 사업자일 가능성

: 다만 해당 캐파가 개발사 자체 인프라인지는 불명확하며, 정식 공개 전 대규모 실제 에이전트 워크로드를 통한 모델, 추론 인프라 스트레스 테스트인지 주목
