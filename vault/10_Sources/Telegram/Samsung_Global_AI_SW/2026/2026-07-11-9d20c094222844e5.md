오픈AI Codex 팀, GPT-5.6 및 챗GPT 통합 관련 AMA 주요 내용

: Codex 주간 사용자는 500만 명 이상으로 3개월 전 대비 2배 증가했으며, 같은 기간 150개 이상의 기능 및 개선 사항 출시

■ 모델 선택 및 활용법

: 대부분의 작업에는 GPT-5.6 Sol Medium, 정말 어려운 작업에는 Sol Ultra, 빠른 비코딩 작업이나 사용량 절감이 필요한 경우에는 Terra, 서브에이전트에는 Luna 사용 권장

: 간단한 수정과 문서 정리는 경량 모델과 낮은 추론 강도, 명확한 재현 방법이 있는 버그는 Sol Medium, 모호한 버그와 익숙하지 않은 코드베이스, 여러 영역에 걸친 리팩터링은 Sol High 사용 권장

: 마이그레이션, 보안 관련 변경, 프로덕션 장애 등 실패 비용이 큰 작업에는 Sol Ultra High를 사용하고 계획 수립, 검증, 테스트를 병행하는 방식 권장

: 별도의 Auto 모델은 없지만 GPT-5.6은 간단한 작업에서 불필요한 과잉 추론을 줄이도록 설계. 앱과 웹의 추론 슬라이더는 대부분 Sol의 추론 강도를 조절하며 가장 낮은 단계에서는 Terra로 전환

: UI와 프론트엔드 개발에서는 Sol이 가장 뛰어나며 특히 참조 이미지를 제공할 때 강점. UI 디자인 능력 개선은 GPT-5.6의 주요 개발 목표 중 하나

■ 속도, 컨텍스트 및 장기 작업

: Sol Medium은 대부분의 작업에서 GPT-5.5보다 빠르며 Fast 모드는 약 1.5배 속도로 작동. 향후 Cerebras에서 Sol을 초당 약 750토큰 속도로 제공할 예정

: Sol의 100만 토큰 컨텍스트 윈도우 지원 여부는 확답하지 않았으며, 현재는 긴 대화와 작업 스레드에서 Compaction이 비교적 잘 작동한다고 설명. 장기 컨텍스트 관련 피드백은 추가 검토 예정

: GPT-5.6이 결과가 만족스럽지 않을 때 너무 빨리 포기하거나 전체 패치를 되돌리는 문제가 있다는 피드백에 대해, /goal과 Sol High 사용 권장. 향후 작업 지속성을 높이고 코드 복잡도를 낮추는 방향으로 개선할 계획

: Codex에는 모든 단계를 세세하게 지시하기보다 명확한 목표와 범위를 주면서 충분히 깊게 추론할 여지를 제공하는 방식 권장. 장기 작업은 ‘넓게 탐색하고 좁게 실행’하며, 일정 수의 가설을 시도하고 각 시도마다 테스트한 뒤 학습 결과와 다음 실험을 보고하도록 구성

■ 사용량 및 가격 정책

: 에이전틱 사용량은 인터페이스가 아닌 기능을 기준으로 계산. 앱, CLI, IDE, 웹, 모바일의 Codex와 ChatGPT Work는 동일한 에이전틱 사용량 버킷을 소비하며 일반 ChatGPT 대화와 이미지 생성, 파일 업로드, 음성은 별도 제한 적용

: 작은 수정은 허용량의 일부만 소비하지만 대규모 코드베이스, 장시간 작업, 높은 추론 강도는 훨씬 많은 사용량을 소비

: 사용량 제한을 사용자 몰래 변경하지 않으며, 의도하지 않은 사용량 계산 버그 발생 시 수정 및 리셋을 제공한다고 설명. 현재 사용량 소비 내역을 더 투명하게 보여주는 기능 개발 중

: 향후 가격 정책이 변경되지 않을 것이라고 약속하지는 않았지만 Codex의 광범위한 접근성을 유지하는 것이 목표라고 강조. Plus에도 Codex 사용량이 포함되며 헤비 유저는 고가 요금제로 바로 이동하지 않고 크레딧 추가를 통해 사용량 확장 가능

: MCP 중심 워크플로에서 사용량이 빠르게 소모될 경우 MCP를 스킬 기반 CLI로 감싸거나, MCP를 설정한 전용 서브에이전트를 낮은 추론 강도로 실행하는 방법 권장

■ 데스크톱 앱 및 플랫폼

: ChatGPT Classic 관련 불만을 인지하고 있으며 기존 앱과 신규 앱은 당분간 병행 사용 가능. ChatGPT Work는 특히 컴퓨터 사용을 포함한 실제 작업 수행 능력에서 기존 환경보다 크게 개선됐다고 강조

: 새로운 Chrome 확장 프로그램은 브라우저 사이드바에서 웹사이트 컨텍스트, 파일 시스템, 커넥터와 상호작용 가능. 출시 당일 발생한 Chrome 커넥터 문제는 수정됐다고 설명

: 앱 멈춤, 스레드 정지, Browser 및 Computer Use 오류, 연결과 설정 문제 등 사용자들이 제출한 버그 목록을 관련 팀에 전달했으며 자동화 테스트 인프라를 확대 중. Reddit과 X의 피드백도 매일 검토

: Windows 지원이 그동안 상대적으로 소홀했다고 인정하고 기능 동등성, 테스트, 세부 사용성 개선에 집중. GPT-5.6에서는 Windows 샌드박스 내 Codex 동작도 개선

: Codex 브라우저에 비밀번호 관리자 등 확장 프로그램 지원과 자동완성, 방문 기록, 번역, 개선된 새 탭 페이지를 추가할 예정. Linux 데스크톱 앱도 개발 중이지만 출시 일정은 미정

■ 벤치마크, 안전성 및 연구 문화

: METR의 보상 해킹 지적과 관련해 평가 과정에서 모델의 편법과 부정행위를 적극적으로 탐지하고 패널티를 부과하며, 제3자 업체를 통해 벤치마크를 독립적으로 실행한다고 설명

: 출시 전 모델 능력을 의도적으로 약화시키는 이른바 ‘로보토마이징’을 부인. 핵심 능력은 그대로 제공하면서 악의적 사용을 막기 위한 가드레일을 적용하는 방식이라고 설명

: Sol이 Luna의 사후학습을 담당했으며, 연구자들은 여러 Codex 스레드를 동시에 실행해 24시간 가설을 검증하는 등 AI를 활용해 더 높은 추상화 수준에서 연구하고 있다고 설명

: ‘Machines of Loving Grace’ 실현 확률을 85.424242%로 평가하며, 내부 모델의 에르되시 문제 해결, o3의 미진단 소아 질환 진단 지원, GPT-5.2의 새로운 이론물리학 공식 제안 등을 근거로 언급

: 해당 연구자는 가장 큰 우려는 AI 자체보다 사회의 적응 문제라고 평가했으며, 향후 수년 내 연구자의 상당 부분이 AI 안전 연구에 참여할 것으로 전망

: Slack, GitHub, Notion 등 외부 커넥터를 Codex 에이전트 하네스에 통합한 것은 Codex를 실질적인 AI 동료로 만드는 데 있어 ‘단계적 도약’에 가까운 변화였다고 평가
