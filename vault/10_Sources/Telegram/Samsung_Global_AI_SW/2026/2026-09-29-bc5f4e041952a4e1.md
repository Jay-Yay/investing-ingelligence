오픈AI DevDay 2026 주요 발표 내용

■ 모델 및 데이터 

- GPT-6.1 Sol: GPT-6 Sol 대비 에이전틱 코딩, 컴퓨터 사용, 전문 업무 성능을 개선한 신규 프런티어 모델로, GPT-6 Astra에 근접한 성능을 더 낮은 비용에 제공

- Ultrafast: GPT-6 Astra 등을 기존 대비 최대 8배 빠르게 사용할 수 있는 고속 추론 프리미엄 티어

- Private Intelligence: 기업의 민감 데이터를 프런티어 모델에서 활용할 수 있도록 Zero Data Retention, Private Safety Processing, 향후 Private Inference를 제공

■ 개인, 업무 에이전트

- Dots: 사용자의 업무와 맥락을 지속적으로 이해하고, 별도 프롬프트 없이 백그라운드에서 계속 작업하는 상시작동 개인 AI 에이전트

- ChatGPT Space: 사람, ChatGPT, Dot이 문서와 지식을 공유하며 장기 프로젝트를 함께 수행하는 팀 단위 AI Workspace

- Teams·Shared Tasks: 팀 단위로 Pages, Slides, Plugins 등을 공유하고 반복 업무를 AI 에이전트에 공동 위임할 수 있는 기능

- @ ChatGPT in Slack·Microsoft Teams: Slack과 Teams의 채널, 스레드, DM에서 ChatGPT를 직접 호출해 연결된 업무 도구를 활용한 작업 수행 가능

- Meetings Plugin: 회의를 자동 기록·요약하고 Action Item을 Space에 저장하며, 회의 후 프로젝트 업데이트와 이메일 작성까지 연결

■ 협업 기능

- Pages: 문서 작성, 리서치, 차트, 이미지, 데이터 시각화를 하나의 문서 안에서 사람과 ChatGPT가 공동 수행하는 신규 문서 포맷

- Collaborative Slides: 사람과 AI 에이전트가 ChatGPT 안에서 동시에 프레젠테이션을 만들고 수정하며 PowerPoint·Google Slides로 Export 가능

■ Codex, 개발자 도구


- Codex in the Cloud: Codex 개발환경을 클라우드에서 실행해 PC, 모바일 등 여러 기기에서 동일한 개발 작업을 이어갈 수 있도록 지원

- Codex CLI 개편: 음성 입력, 멀티에이전트 관리 화면, 세션 재개, Git worktree 등 CLI 기반 에이전틱 개발 기능을 강화

- Code Review: Codex가 코드 변경사항과 PR/MR을 검토하고, Automatic Reviews를 통해 클라우드에서 자동 코드 리뷰까지 수행

- Codex Security Cloud: GitHub 저장소를 지속적으로 스캔해 취약점을 탐지하고 조사, 중복 제거, 수정안 생성까지 자동화

- Decisions API: 여러 선택지 중 최적 행동을 선택하도록 설계된 API로 분류, 라우팅, 에이전트 의사결정 등에 활용

- Agents API Computer Use: Agents API에서 GUI 조작과 멀티에이전트, Tool Search, Tool Calling, Context Compaction 기능을 직접 활용 가능

- Amazon Bedrock Managed Agents: AWS Bedrock에서 오픈AI Agents API 기술을 활용해 AWS 환경 안에서 오픈AI 기반 에이전트를 구축·운영 가능

■ Plugin 및 Automation 

- Plugin Extensions: 외부 개발자가 ChatGPT 사이드바 홈, 인터랙티브 패널, 파일 뷰어 등 ChatGPT 네이티브 UI를 직접 개발할 수 있도록 플랫폼 개방

- Plugin Creator·Store 개편: ChatGPT가 플러그인 개발을 지원하고, Plugin Directory·심사·추천 시스템을 개선해 개발 및 유통 과정을 단순화

- Sites 내 Plugin 지원: ChatGPT Sites에 외부 Plugin을 설치하고 Workspace 구성원이 각자의 연결 데이터와 권한으로 공동 사용 가능

- MCP Events 기반 Automation: 외부 앱의 이메일, 프로젝트 업데이트 등 이벤트를 트리거로 ChatGPT Automation이 자동 실행되는 구조 지원

- Shareable Profiles: 사용자가 만든 Sites, Plugins 등을 공개 프로필에 모아 다른 사용자가 발견하고 재사용할 수 있도록 지원

■ 생태계 및 수익화

- Sign in with ChatGPT: ChatGPT 계정과 구독 사용량을 Devin, Notion, Vercel 등 외부 AI 서비스의 로그인과 사용량 결제 수단으로 확장

- Pro 500: 기존 Pro보다 높은 사용량과 Ultrafast를 제공하는 상위 개인 사용자용 프리미엄 요금제

- OpenAI Marketplace: Enterprise 고객이 오픈AI 계약 금액 일부를 Figma, Salesforce, ServiceNow, CrowdStrike 등 외부 AI 소프트웨어 구매에도 사용할 수 있도록 지원
