알리바바, Qwen4 아키텍처 프리뷰 Qwen3.8-Flash-Next 공개

: 알리바바 Qwen은 차세대 Qwen4에 적용될 신규 아키텍처의 프리뷰 모델 Qwen3.8-Flash-Next를 오픈웨이트로 공개

: 125B 메인 모델에 51B N-gram Embedding을 추가했으며, 토큰당 활성 파라미터는 6B

: 핵심 변화는 Gated DeltaNet과 Qwen Sparse Attention을 결합한 GDN+QSA, Residual Stream을 4개로 확장한 Gated Residual, 추가 연산을 거의 늘리지 않고 모델 용량을 확장하는 N-gram Embedding, Muon Optimizer 도입

: QSA는 긴 Context를 Micro-block 단위로 압축해 중요한 영역만 선택적으로 Attention. 1M Context에서 Prefill과 Decode를 각각 최대 7.6배, 4.9배 가속하며, Prefix Cache Hit Rate 90% 환경에서는 Qwen3.7-Plus 대비 Prefill Throughput 8.6배

: Qwen3.7-Plus 대비 학습 비용은 약 1/9에 불과하지만 코딩과 오피스 Agent 성능은 상회. SWE-bench Pro 62.5, CoWorkBench 73.9, JobBench 55.7을 기록하며 일부 벤치마크에서는 Claude Opus 4.6 Max도 상회

: 기본 262K Context를 지원하고 YaRN으로 1M까지 확장 가능. QwenCloud의 Qwen3.8-Flash는 기본 1M Context와 내장 Tool을 제공하며 가격은 입력 $0.16, 출력 $0.47 / 100만 토큰

: Qwen3-Next와 마찬가지로 차세대 아키텍처를 정식 모델 출시에 앞서 공개한 모델로 규정

: Qwen4는 성능 향상과 함께 Long Context 및 Agent 워크로드의 연산·메모리 비용 절감을 핵심 방향으로 가져갈 전망
