"교수가 쓰면 교수, 막 쓰면 폐기물"… AI는 사용자의 지적 수준을 비추는 거울

인공지능(AI)의 본질을 관통하는 원리는 "교수가 쓰면 교수의 성능을 내고, 무지한 자가 쓰면 폐기물을 만들어낸다"는 것이다. AI는 스스로 완벽한 정답을 창조하는 마법의 지팡이가 아니라, 질문을 던지는 사용자의 도메인 지식과 유기·논리적 뎁스(Depth)를 그대로 증폭시키는 '거울'에 불과하다. 내가 '절기 알람 프로그램'을 만들다가 느낀 것임. 번거로운 공공 API 인증 대신 자체 계산 로직을 짜달라고 AI에게 요구했을 때, AI는 오차가 발생하는 엉성한 프랑스식 역법을 가벼운 해결책이랍시고 들이민다. 결과 나와서 대조해서 잘못 되어서 왜 틀렸냐고 캐묻고 나서야 한국천문연구원(KASI)의 정밀한 계산법이 필요하다고 실토하더라. 그래서 천문연구원이랑 같은 방식으로 계산해달라고 하니까 구현해 준 NASA 기반의 계산식조차 몇 년에 한 번씩 오차가 발생한다는 치명적인 결함을 숨긴 채 천연덕스럽게 결과물을 내놓는다. 사용자가 해당 분야의 지식이 없다면 기계가 던져준 그럴싸한 오답을 정답으로 믿고 파멸적인 결함을 시스템에 이식하게 되는 것이다.

이러한 일련의 과정은 최근 IT 업계에서 맹신하고 있는 인공지능의 허상을 정확히 찌른다. 만약 이 절기 알람 프로젝트를 목적 특화 에이전트에게 전적으로 위임했다면 어떻게 되었을까. 에이전트는 사용자의 초기 지시(API 없이 계산할 것)에 매몰되어 천문학적 오차가 나는 NASA 계산식을 꾸역꾸역 코드에 집어넣거나, 뒤늦게 방향을 틀어 공공 API를 연결해 놓고도 '2년에 한 번씩 인증을 갱신해야 하는' 치명적인 유지보수 폭탄을 사용자에게 남겨두었을 것이다. 기계는 주어진 태스크(Task)를 기계적으로 수행할 뿐, "이 방식이 과연 현실의 서비스 운용 관점에서 최적인가?"를 의심하거나 궤도를 수정하는 메타 인지(Metacognition) 능력이 결여되어 있기 때문이다.

결국 이 난극을 해결한 궁극적인 최적해는 복잡한 천문학 계산식도, 2년마다 갱신해야 하는 귀찮은 공공 API도 아닌 이미 완성되어 있는 '구글 캘린더'를 끌어다 쓰는 인간의 직관적 기지였다. 아무리 뛰어난 프론티어 모델이나 특화 에이전트라 할지라도, 전체 시스템의 아키텍처를 조망하고 가장 효율적인 우회로를 찾아내는 것은 철저히 설계자의 '짬(경험)'과 통찰력의 영역이다. 내가 무엇을 모르는지 파악조차 하지 못한 채 맹목적으로 AI의 아웃풋에 의존한다면 결국 기계의 나태함과 환각(Hallucination)에 농락당할 뿐이다. AI 시대의 진정한 알파(Alpha)는 코드를 짜는 속도가 아니라, 기계가 엉뚱한 길로 빠지지 않도록 통제하고 가장 현실적이고 효율적인 아키텍처를 지시할 수 있는 '질문의 격(格)'에 있다.
