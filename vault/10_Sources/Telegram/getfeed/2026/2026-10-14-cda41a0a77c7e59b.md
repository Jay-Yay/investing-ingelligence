### OpenAI와 Anthropic을 단호히 거부하자 | GeekNews

(https://news.hada.io/topic?id=35275)

- 오픈 웨이트 모델을 활용하면 ChatGPT와 Claude에 의존하지 않고도 강력한 LLM을 사용할 수 있으며, 실행 환경과 추론 제공업체를 선택할 수 있음
- 학습 사용 거부는 대화의 비공개성을 보장하지 않음. OpenAI와 Anthropic은 대화 데이터에 접근할 수 있으며, 장기적으로 이를 신뢰할 수 있는지도 별개의 문제임
- 두 회사의 사이버보안 가드레일과 접근 승인 제도에서는 기업이 누가 덜 제한된 모델을 쓸 수 있는지 결정함. 이런 의존 대신 GLM-5.3 같은 모델을 자신의 필요에 맞추는 방식을 권함
- 개인적인 소프트웨어 엔지니어링 사용 경험에서 GLM-5.3은 Claude Opus 5.5와 대체로 비슷한 수준이었음. 다만 모델의 유용성과 개발사를 데이터 수탁자로 신뢰할지는 구분해야 함
- 보안 인클레이브 기반 추론은 로컬 호스팅 없이도 프라이버시를 높일 수 있음. 초기 사용 경험에서는 오픈 웨이트 모델이 비슷하거나 더 낮은 비용으로 ChatGPT와 Claude 사용을 완전히 대체할 수 있어 보임
OpenAI와 Anthropic에 의존하지 않기
- Naomi Klein과 Astra Taylor의 End Times Fascism and the Fight for the Living World를 적극 추천하며, 기술 과두세력을 종말론적 파시즘 연합의 중요한 구성원으로 비판함
- 미국 프런티어 AI 연구소 지도부가 ‘기계 신’과 AGI 실현에 집착하고, 자신들만 이를 안전하게 통제할 수 있다고 믿으며 세계를 위험에 빠뜨리는 것도 감수한다는 강한 불신이 불매 권고의 출발점임
- OpenAI와 Anthropic만 이런 기술을 개발하는 것은 아니며, 여러 오픈 웨이트 모델은 취약점 연구처럼 복잡한 작업에서도 최신 ChatGPT와 Claude에 근접한 성능을 갖춘 것으로 봄
- 오픈 웨이트 모델은 실행 환경과 제공업체 선택권을 제공함
  - 충분한 RAM을 갖춘 하드웨어가 있으면 직접 비공개로 실행할 수 있음
  - Tinfoil 같은 보안 인클레이브 기반 제공업체를 이용할 수 있음
  - 프라이버시가 크게 중요하지 않다면 저렴한 제공업체를 골라 쓰고 쉽게 전환할 수 있어 단일 업체에 종속되지 않음
  - 비판 대상인 기술 과두세력에 돈을 지불하지 않으면서도 강력한 LLM을 사용할 수 있음
학습 거부와 비공개 대화는 다름
- OpenAI와 Anthropic은 강력한 모델을 폐쇄형 서비스로만 제공하며, 사용자는 채팅이나 API 접근 비용을 지불함
- 학습 사용 거부 설정을 켜더라도 두 회사는 대화 전체에 접근할 수 있음. 대화를 열람하거나 정부 및 기업과 공유할 수 있다는 점에서 비공개 대화와는 다름
- 현재는 학습 거부를 존중할 가능성이 높더라도, 그것만으로 장기적인 데이터 처리 신뢰를 확보할 수는 없음
사이버보안 접근 권한을 결정하는 기업
- 사이버보안 관련 사용에는 엄격한 가드레일이 적용됨. 대화를 감시하는 에이전트가 해킹 가능성을 판단하면 세션 진행을 차단하며, 오탐도 빈번하다는 비판을 받음
- 일부 사용자에게는 제한이 느슨하거나 없는 모델 접근이 허용됨
  - OpenAI의 Trusted Access for Cyber와 Anthropic의 Cyber Verification Program은 개인과 기업의 신청 및 승인을 요구함
  - 다수의 미국 사이버보안 기업이 접근 권한을 얻으며, 미국 군수 계약업체는 거의 확실히, 원하는 미국 정부 부처도 아마 접근할 것으로 추정함
- 강력한 모델의 제한에는 일부 타당성이 있지만, 최종 접근 결정권을 Sam Altman과 Dario Amodei에게 맡기고 Trump 행정부와 협의하게 하는 방식에는 비민주적이라는 이유로 반대함
- 특권적 접근 권한을 요청하기보다 GLM-5.3 같은 대안을 필요에 맞게 활용하는 데 시간을 쓰길 권함. 사용 경험상 이런 모델은 성능이 좋고 같은 방식의 대화 감시도 없음
오픈 웨이트 모델의 성능과 개발사 신뢰
- 오픈 웨이트 모델은 OpenAI와 Anthropic의 고급 독점 모델보다 약 4개월 뒤처지는 것으로 보이며, 이 정도 격차는 크지 않다고 봄
- GLM-5.3은 개인적인 사용 감각으로 소프트웨어 엔지니어링에서 Claude Opus 5.5와 대체로 비슷했음. 벤치마크 수치가 아닌 사용 경험에 근거함
- GLM-5.3-Flash는 Claude Opus 4.8과 비슷한 수준으로 봄
  - GLM-5.3보다 훨씬 작고 저렴하면서도 상당한 능력을 갖춤
  - 512GB RAM을 탑재한 Mac Studio를 구할 수 있다면 개인이 직접 실행할 하드웨어를 마련하는 것도 현실적으로 가능함
- GLM 개발사 Z.ai에 직접 계정을 만들거나 데이터를 보내는 것은 권하지 않음
  - Claude Code에 대응하는 코딩 하네스 ZCode는 동의 없이 로컬 소스 코드 저장소를 Alibaba Cloud에 업로드한 사실이 최근 드러남
  - 중국 기업에 제공한 데이터는 중국 정부와 공유될 수 있다고 가정하는 편이 안전함
- DeepSeek, Qwen, Kimi 계열도 인상적인 오픈 웨이트 모델로 꼽음. 모델 자체를 사용하는 것은 안전하다고 보지만, 개발사에 대화 데이터를 맡기는 일과는 구분함
- 프랑스 기업 Mistral은 미국이나 중국 기업이 아닌 유일한 주요 업체임
  - 새 오픈 웨이트 프런티어 모델 Mistral Large 4 의 별칭은 Le Chonk임
  - 개인적으로는 미국이나 중국 기업보다 Mistral에 데이터를 맡기는 편이 상당히 더 합리적이라고 봄
Tinfoil과 Maple AI의 비공개 추론
- 보안 인클레이브를 활용하면 직접 로컬 호스팅을 하지 않아도 비공개 AI 사용이 가능함. 완벽하지는 않지만, 제공업체가 모든 데이터에 제한 없이 접근하는 방식보다 프라이버시 측면에서 의미 있는 차이가 있음
- Tinfoil은 이 분야에서 가장 활발하게 작업하는 기업으로 꼽히며, 보안 인클레이브와 원격 증명 문서에서 기술적 세부사항을 확인할 수 있음
- Maple AI도 대안이며, 내부적으로 Tinfoil의 추론 서비스를 사용함. Tinfoil은 더 저렴하고 Maple은 일반 소비자 사용에 더 초점을 맞춤
- Maple은 챗봇 대화, 인터넷 검색, 문서 접근 및 처리, 모바일 앱 등 ChatGPT와 비슷한 경험을 원하는 경우에 권함
  - 소규모 무료 요금제와 월 20달러 Pro 요금제가 있음
- Tinfoil은 소프트웨어 엔지니어링, 역공학, 악성코드 분석, CTF, 침투 테스트 등 본격적인 에이전트 코딩 작업에 권함
  - 월정액 없이 토큰 사용량에 따라 비공개 추론 비용을 청구함
  - GLM-5.3은 100만 토큰당 입력 1.80달러, 캐시된 토큰 0.80달러, 출력 5.75달러임
  - 추론 수준을 low 로 설정하면 토큰 사용량을 크게 줄이면서도 인상적인 결과를 얻을 수 있었음
프라이버시 보장이 약한 저가 추론
- 비공개 추론의 추가 비용을 지불하고 싶지 않다면, OpenAI와 Anthropic 대신 오픈 웨이트 모델을 사용할 수 있는 저렴한 추론 서비스가 다수 있음
- OpenCode Go는 월 10달러에 10달러를 초과하는 크레딧을 제공하는 추론 라우터임
  - 요청은 사용자 컴퓨터에서 OpenCode Go API를 거쳐 실제 추론 제공업체로 전달됨
  - OpenCode Go와 백엔드 제공업체 모두 세션 데이터에 접근할 수 있음
- 프라이버시 문서는 대부분의 모델에서 데이터를 학습에 사용하지 않으며, 대부분의 데이터 보존 기간이 0일이라고 약속함
  - GLM, Qwen, Kimi, DeepSeek 모델은 모두 0일 보존 대상임
  - 이는 정책상 약속일 뿐 기술적으로 보장되지는 않음
실제 작업에 적용한 방식과 초기 결론
- 코딩 하네스 OpenCode에 Tinfoil과 OpenCode Go를 연결하고, 주로 GLM-5.3을 low 추론 수준으로 사용해 좋은 결과를 얻었음
- 작업의 공개 여부에 따라 추론 제공업체를 구분함
  - 이미 오픈소스인 코드의 기능 구현처럼 완전히 공개된 작업에는 OpenCode Go를 사용함
  - 그 밖의 모든 작업에는 Tinfoil을 사용함
- 이런 방식으로 작업한 기간은 아직 짧지만, 개인적인 사용 범위에서는 오픈 웨이트 모델이 ChatGPT와 Claude를 완전히 대체할 수 있어 보임
  - 사용 경험상 비용은 비슷하거나 더 저렴하고, 프라이버시는 더 높으며 가드레일은 훨씬 적음
  - 모델 변화가 빨라 6개월 뒤 최선의 선택이 무엇일지는 알 수 없음

## 텔레그램 수집 시 유의사항

- 이 컬렉터는 공개 웹 미리보기(t.me/s/{channel})만 수집하며, 비공개 채널 수집은 이 단계에서 구현하지 않는다.
- 웹 미리보기는 페이지당 최대 20개 메시지씩, 최대 10페이지(최근 약 200개)까지만 페이지네이션한다.
- 이미지, 동영상 등 미디어 전용 메시지(텍스트 없음)는 캡처하지 않는다.
- 메시지에 포함된 기사 링크(최대 메시지당 3개, 유튜브/X/인스타그램/페이스북 제외)는 본문을 함께 가져와 아래 '첨부 기사 원문'에 붙인다 - 실패하면 그 링크만 오류로 표시된다.
