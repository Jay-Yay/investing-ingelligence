  - 학습과 경사 정보는 금지하고, 평가 문제는 Astra에 공개하지 않음
  - 평가는 최대 32,768토큰, temperature 0.6, top-p 0.95, top-k 20, presence penalty 1.5로 수행함
- 주요 장애는 답을 완성하지 못하는 반복 추론이었으며, 이는 Qwen의 모델 카드가 경고하는 문제이기도 함
  - 첫 연습 응답 96개 중 85개가 32,768토큰 한도에 도달함
  - Astra는 15번과 19번 층의 MLP가 기록하는 특정 방향을 원인으로 추적하고, 각 층에서 해당 방향을 강하게 기록하는 출력 열 64개씩을 수정함
  - 최종 변경량은 131,072개 가중치, 전체의 0.016% 임
- 수정 과정에서는 단일 뉴런 비활성화에서 시작해 층별 방향 제거, 개입 강도 조절, 층별 분리 실험, 같은 크기의 무작위 방향 대조 실험을 수행함
  - 최종적으로 전체 MLP를 수정하는 대신 층당 64개 뉴런에 집중한 편집을 선택함
  - 진단에서는 기존에 토큰 한도에 걸리던 응답을 완성하게 된 경우가 개선의 대부분을 차지했고, 원래 끝까지 답하던 응답의 전체 정확도는 유지됨
  - 수정 후 정답 응답도 상당한 추론 길이를 유지해, 단순히 조기 종료를 강제한 결과와는 달랐음
- 순전파 50회 조건에서 수학과 지시 이행 성능이 함께 향상됨
  - MATH-500은 7.9%에서 48.1%로 높아짐
  - GSM8K는 13.8%에서 67.1%로 상승함
  - IFEval은 21.0%에서 62.3%로 개선됨
  - MATH-500에서 토큰 한도에 도달한 응답은 93.0%에서 33.1%로 줄어듦
- 실행 예산이 적으면 반복 추론 감소가 제한적이었음
  - 10회 조건의 MATH-500은 12.3%, GSM8K는 25.7%, IFEval은 49.0%, 토큰 한도 도달률은 87.2%임
  - 25회 조건에서는 각각 14.1%, 25.1%, 39.9%, 86.4%로, 예산 증가가 모든 지표의 일관된 향상으로 이어지지는 않음
- 평가는 MATH-500, GSM8K 외에 Minerva Math, OlympiadBench, AMC23, GPQA Diamond, IFEval, MMLU-Pro까지 수행했으며, 벤치마크별로 정한 표본 수를 사용함

반복 추론을 고치는 것은 새로운 수학 능력을 추가하는 것과 다름
  - Qwen의 수정은 이미 풀 수 있는 문제의 답을 끝까지 작성하게 하는 효과였음
  - 반복 추론이 드문 Gemma 3 270M에서는 유의미한 개선을 얻지 못함
  - 토큰 한도 도달률은 Qwen의 93%와 달리 8.5%였으며, 실패는 잘못된 산술이나 유효하지 않은 대수 단계 같은 일반적인 추론 오류였음
  - 하나의 구성 요소를 꺼서 해결할 수 있는 공통 원인을 찾지 못함
  - 숫자에 반응하는 뉴런 하나의 강도를 두 배로 높이는 등 표적 편집을 시도했지만, MATH-500은 기본 6.8%에서 순전파 예산별 7.0~7.7% 수준에 머물렀고 유의미한 개선은 확인되지 않음
  - Gemma는 모델 카드에 맞춰 temperature 1.0, top-k 64, top-p 0.95, 최대 8,192토큰으로 평가하고 문제당 4개 표본을 평균함
  - 이번 실험에서 가중치 편집은 기존 능력을 가리던 장애는 제거했지만, 부족한 능력을 추가하지는 못함

- 현재 결과는 초기 단계이며, 문맥 길이와 하네스의 비효율이 능력을 제한함
  - 작은 모델의 성공을 모든 대형 모델의 해석과 수정 능력으로 확대할 수 있는 결과는 아님
  - 향후 LLM이 자연어와 가중치 공간을 연결해 기계적 해석 가능성과 신경망 최적화 방식을 크게 바꿀 가능성을 탐색하고 있음
- 향후 활용 가능성은 다음과 같으며, 아직 달성된 기능이 아니라 전망임
  - 평가 없는 감사: 추론이나 벤치마크를 실행하지 않고 가중치에서 숨은 능력, 문제, 백도어 등을 찾아낼 가능성이 있음
  - 최적화 비용 절감: 데이터 수집과 전체 학습 루프 대신 한 번의 가중치 초기화로 시간과 연산을 줄일 가능성이 있음
  - 데이터 없는 능력 조정과 망각 학습: 자연어 요청으로 소수 가중치만 수정해 능력을 추가하거나 제거하고, 나머지 모델을 유지해 파국적 망각을 피하는 방식이 가능할 수 있음
  - 재귀적 자기 개선: 학습 작업을 실행하는 코드를 작성하는 수준을 넘어, 자기 가중치나 후속 모델의 가중치를 직접 점검하고 개선할 가능성도 있음
  - 서로 다른 구조 간 모델 병합: 같은 구조의 가중치를 평균하는 대신 추론 모듈 같은 회로를 다른 구조의 모델에 재학습 없이 이식하는 방식도 가능할 수 있음
- 가중치 공간 프로그래밍 능력을 표준화해 평가할 벤치마크와 하네스를 개발 중임

## 텔레그램 수집 시 유의사항

- 이 컬렉터는 공개 웹 미리보기(t.me/s/{channel})만 수집하며, 비공개 채널 수집은 이 단계에서 구현하지 않는다.
- 웹 미리보기는 페이지당 최대 20개 메시지씩, 최대 10페이지(최근 약 200개)까지만 페이지네이션한다.
