### Qwen3.8 27B, Artificial Analysis 지능 지수 52점 기록 | GeekNews

(https://news.hada.io/topic?id=32599)

- Alibaba의 Qwen3.8 27B는 비슷한 규모의 오픈 가중치 모델 중앙값 9를 크게 웃도는 Artificial Analysis Intelligence Index 52점을 기록함
- 270억 매개변수 추론 모델로 텍스트·이미지를 입력받아 텍스트를 출력하며, Apache 2.0 라이선스로 가중치를 공개해 자체 호스팅과 상업적 이용이 가능함
- Intelligence Index 평가에서 1억 6,000만 출력 토큰을 생성해 동급 모델 중앙값 4,300만 토큰보다 훨씬 장황함
- 입력과 출력의 표시 가격은 모두 100만 토큰당 $0.00이지만, 속도와 Intelligence Index 작업당 비용은 제공되지 않음
- 컨텍스트 창은 요약 표에 256k 토큰, FAQ에 260k 토큰으로 다르게 기재돼 있어 실제 활용 전 제공자별 한도를 확인해야 함
모델 구성과 공개 조건
- Alibaba가 만든 Qwen3.8 27B는 2026년 8월 14일 출시된 270억 매개변수 오픈 가중치 모델임
- 복잡한 문제에 답하기 전 확장 사고 또는 연쇄적 사고를 수행하는 추론 모델 버전이며, 비추론 변형도 별도로 존재할 수 있음
- 텍스트와 이미지를 입력받고 텍스트를 출력하는 멀티모달 모델로, 이미지 분석·묘사·질의응답을 지원함
- Apache 2.0 라이선스로 상업적 이용이 가능하며, Hugging Face에서 가중치를 내려받아 자체 호스팅할 수 있음
- 모델 표의 컨텍스트 창은 256k 토큰으로, Arial 12포인트 기준 약 384쪽 분량의 A4 문서에 해당함
  - FAQ에는 260k 토큰으로 별도 기재돼 있음
  - 컨텍스트 한도는 입력과 출력 토큰의 합이며, 출력 한도는 일반적으로 이보다 훨씬 낮고 모델마다 다름
지능 평가 결과
- Qwen3.8 27B는 Artificial Analysis Intelligence Index 52점으로, 같은 크기 등급의 오픈 가중치 모델 중앙값 9를 크게 웃돎
- Intelligence Index v4.1.1은 다음 9개 평가를 종합함
  - GDPval-AA v2: 에이전트 기반 실세계 업무
  - 𝜏³-Banking: 에이전트 도구 사용
  - Terminal-Bench v2.1: 에이전트 코딩과 터미널 사용
  - SciCode: 코딩
  - Humanity's Last Exam: 추론과 지식
  - GPQA Diamond: 과학적 추론
  - CritPt: 물리학 추론
  - AA-Omniscience: 지식과 비환각 성능
  - AA-LCR: 긴 컨텍스트 추론
- 전반적인 지능 점수는 여러 용례를 포괄하지만, 실제 적용 분야에 따라 특정 개별 평가가 더 중요할 수 있음
지식 신뢰성과 개방성 측정
- AA-Omniscience Index는 정답에 보상하고 환각에 벌점을 부여하되, 답변 거부에는 벌점을 주지 않는 방식으로 지식 신뢰성을 평가함
- 점수 범위는 -100~100이며, 0은 정답과 오답 수가 같고 음수는 오답이 정답보다 많다는 뜻임
- Artificial Analysis Openness Index는 모델의 개방성을 0~100의 정규화 척도로 측정하며, 점수가 높을수록 더 개방적임
토큰 사용량과 장황성
- Intelligence Index 전체 평가에서 생성한 출력은 1억 6,000만 토큰으로, 동급 오픈 가중치 모델 중앙값 4,300만 토큰보다 많음
- 작업당 출력 토큰 수는 각 평가의 출력량에 해당 벤치마크의 상대 가중치를 곱한 뒤, 반복 실행을 제외한 작업 수로 나눠 계산함
- 많은 출력량으로 인해 장황성 항목은 4점 만점에 4점으로 분류됨
가격과 비용 계산
- 표시 가격은 입력과 출력 모두 100만 토큰당 $0.00임
  - 동급 중앙값은 입력 $0.04, 출력 $0.15임
  - 속도와 Intelligence Index 작업당 비용은 N/A로 제공되지 않음
- 작업당 비용은 입력, 캐시 적중, 캐시 쓰기, 추론, 답변 토큰 가격을 작업 수로 나눈 뒤 Intelligence Index 가중치를 적용해 산출함
- 전체 평가 실행 비용은 반복 실행을 제외한 평가별 토큰 사용량과 각 토큰 유형의 가격으로 계산됨
- 캐시 가격은 이전에 처리한 프롬프트의 캐시 적중 가격을 뜻하며, 캐시 쓰기와 저장 비용은 별도로 청구되고 제공자마다 다름
비교 기준과 모델 크기
- 추론 모델은 추론·비추론 모델 모두와 비교하고, 비추론 모델은 다른 비추론 모델과만 비교함
- 오픈 가중치 모델은 같은 매개변수 규모 등급 안에서 비교함
  - Tiny: 4B 이하
  - Small: 4B 초과~40B
  - Medium: 40B 초과~150B
  - Large: 150B 초과
- Qwen3.8 27B는 Small 등급에 속함
- 독점 모델은 입력·출력 가격을 3:1로 혼합해 산정한 가격대별로 비교함
  - 100만 토큰당 $0.15 미만
  - $0.15~$1
  - $1 초과
- 총매개변수는 학습 가능한 가중치와 편향 전체를, 활성 매개변수는 추론의 각 순전파에서 실제 실행되는 수를 뜻함
  - MoE 모델은 토큰마다 일부 전문가만 선택하므로 활성 매개변수가 총매개변수보다 적음
  - Dense 모델은 모든 매개변수를 사용하므로 두 수치가 같음
