### Tencent Hy4 프리뷰 공개 | GeekNews

(https://news.hada.io/topic?id=33023)

- Tencent가 전체 770B·활성 49B 매개변수와 100만 토큰이 넘는 컨텍스트 창을 갖춘 차세대 LLM Hy4 프리뷰를 공개하고 오픈소스로 배포함
- 코딩·문서 작업·게임 개발·과학 연구 같은 실제 생산성 작업에 초점을 맞췄으며, Tencent 내부 블라인드 평가에서 GLM-5.3과 Kimi K3를 소폭 앞섬
- Hy4는 훈련 방법·데이터 전략·평가 체계·저수준 연산자 개선안을 제안하고 직접 실험하며, 결과를 다음 탐색에 반영하는 초기 자기 개선 루프에 참여함
- 자체 추론 시스템의 병목을 분석해 연산자 융합과 통신을 최적화했으며, Tencent는 이를 통해 기준 대비 종단 간 처리량이 31.8% 향상됐다고 밝힘
- WorkBuddy·CodeBuddy와 Tencent 제품, TokenHub·OpenRouter API에서 이용할 수 있으며 가격은 100만 토큰당 입력 0.834달러, 출력 2.501달러, 캐시 적중 0.042달러
실제 생산성 작업을 겨냥한 대형 모델
- Hy4 preview는 전체 770B, 활성 49B 매개변수와 100만 토큰 이상의 컨텍스트 창을 갖춘 오픈소스 대규모 언어 모델
  - 모델 크기와 컨텍스트 길이, 데이터 양을 크게 늘림
  - 사전 훈련과 사후 훈련을 모두 발전시켜 전반적인 성능을 높임
- CodeBuddy·WorkBuddy와 공동 설계해 실제 생산성 환경의 사용자 경험을 최적화함
  - 소프트웨어 엔지니어링·게임·금융·보안 분야에서 Tencent 전문가와 함께 만든 고품질 훈련 데이터를 사용함
- 주요 활용 영역은 다음과 같음
  - 소프트웨어 엔지니어링에서는 긴 컨텍스트가 필요한 개발 작업의 이해·계획·디버깅·검증 능력을 강화하고, 프런트엔드의 시각적 품질과 상호작용 경험도 개선함
  - 사무·분석 영역에서는 복잡한 업무 환경을 이해하고 금융 분석을 수행하는 능력을 강화함
    - 데이터 분석과 문서 간 협업을 최적화함
    - 정보 처리부터 문서·스프레드시트·프레젠테이션 제작까지 전체 작업 흐름을 지원함
  - 게임 개발에서는 하나의 자연어 요청으로 플레이 가능한 프로토타입을 생성하고 게임 엔진과 연동할 수 있음
    - 이후 여러 차례 대화하며 복잡한 게임 프로젝트를 계속 다듬는 것도 가능함
  - 과학 연구에서는 복잡한 문제를 이해·추론·해결하는 능력을 강화함
    - AI 연구개발, 분자 동역학 시뮬레이션, 응집물질물리학, 기초수학 분야에서 개선됨
내부 평가에서 기존 오픈소스 모델을 소폭 앞섬
- Tencent 전문가 163명이 실제 엔지니어링 작업 203개를 수행하는 내부 블라인드 평가를 진행함
- 4점 만점의 평균 점수는 다음과 같음
  - Hy4 프리뷰: 2.99
  - Kimi K3: 2.94
  - GLM-5.3: 2.92
- Hy4가 가장 높은 점수를 기록했지만 차이는 크지 않으며, Tencent가 자체 제품 환경에서 진행한 내부 평가라는 점은 감안할 필요가 있음
자신의 개발과 추론 최적화에 참여
- Hy4 preview는 처음으로 자체 개발 과정에 참여해 초기 단계의 재귀적 자기 개선 루프를 구성함
  - 훈련 방법과 데이터 전략, 평가 체계, 저수준 연산자의 자동 최적화에 참여함
  - 접근법을 제안하고 실험을 실행한 뒤 결과에 따라 반복 개선함
  - 생성된 코드·로그·피드백은 다음 탐색 단계에 다시 투입됨
- 추론 시스템의 병목을 자율적으로 분석하고 연산자 융합과 통신을 여러 차례 최적화함
  - 기준 대비 종단 간 처리량이 31.8% 증가함
  - 서로 다른 컨텍스트 길이와 동시성 수준에서도 일관된 향상을 기록함
공개 범위와 이용 방법
- 오픈소스 모델로 공개되며 WorkBuddy, CodeBuddy, Yuanbao, ima 등 Tencent 제품에서도 제공됨
- Tencent Cloud TokenHub와 OpenRouter를 통해 API로 연결할 수 있음
- 출시 후 2주 동안 WorkBuddy와 CodeBuddy에서 Hy4 프리뷰를 무료로 제공함
- API 가격은 100만 토큰 기준 입력 0.834달러, 출력 2.501달러, 캐시 적중 0.042달러임
- 프리뷰에서 실제 사용자 피드백을 수집한 뒤 정식 버전을 출시하며, 다른 Hy4 계열 모델도 이어서 공개할 계획임
