### Bonsai 2 27B, 성능 98.2%를 유지하며 모델 크기를 5.9GB로 압축 | GeekNews

(https://news.hada.io/topic?id=33869)

- PrismML이 Qwen3.8 27B 기반의 3진 가중치 모델을 공개함. 전체 정밀도 모델보다 크기를 9배 이상 줄였으며, 종합 벤치마크 성능 98.2% 를 유지
- 가중치를 −1, 0, +1 세 값과 보정용 배율로 표현해 가중치당 실효 비트 수를 1.76비트로 낮춤
- 종합 83.9점으로 코딩과 수학 성능은 원본에 근접하고 지시 따르기는 이를 웃돌며, 이전 Bonsai 세대보다 추론과 비전, 장기 에이전트 작업 성능도 개선함
- 자체 측정 처리량은 RTX 5090에서 최대 143토큰/초, M5 Max에서 46.8토큰/초이며, 로컬 코딩 에이전트와 컴퓨터 사용 데모를 공개. 에너지 효율이 40% 높음
- 262K 토큰 컨텍스트와 텍스트/이미지 입력을 지원하고, CUDA와 MLX용 전용 저비트 커널로 실행하며 가중치는 Apache-2.0 라이선스로 공개
압축 방식과 이전 세대 대비 변화
- Ternary Bonsai 2 27B는 두 달 전 공개한 첫 Bonsai 27B의 후속 모델로, 기반 모델을 Qwen3.8 27B로 변경함
  - 추론, 코딩, 비전, 장기 에이전트 작업 성능을 개선하면서 작은 메모리 사용량, 높은 로컬 처리량, 에너지 효율을 유지함
  - 전체 정밀도 모델 대비 성능 유지율은 이전 세대의 95%에서 98% 이상으로 높아짐
- 3진 가중치 {−1, 0, +1} 에 FP16 그룹별 스케일링을 결합하고, 저비트 표현을 언어 모델 전체에 적용함
  - 가중치당 실효 비트 수는 1.76비트, 전체 모델 크기는 5.9GB임
  - 크기는 전체 정밀도 모델의 9분의 1 미만이면서 종합 벤치마크 성능의 98.2%를 유지함
- 262K 토큰 컨텍스트 윈도와 멀티모달 텍스트/이미지 입력을 지원함
벤치마크 성능과 로컬 활용
- 사고 모드(thinking mode) 기준 종합 점수는 Ternary Bonsai 2 27B가 83.9점, Qwen3.8 27B가 85.4점, Qwen3.6 27B가 83.6점임
- 영역별 점수는 아래와 같으며, 수치는 Bonsai 2 / Qwen3.8 / Qwen3.6 순서임
  - 에이전트 및 도구 호출: τ²-bench, BFCLv3에서 77.57 / 79.74 / 80.05점임
  - 코딩: HumanEval+, LiveCodeBench v6, MBPP+, BigCodeBench에서 81.58 / 82.17 / 82.57점임
  - 지시 따르기: IFBench, IFEval에서 82.66 / 81.25 / 74.53점임
  - 지식 및 추론: MMLU-Redux, GPQA Diamond, AA-LCR에서 83.95 / 86.66 / 84.71점임
  - 수학: AIME 2026, AIME 2025, GSM8K, MATH-500에서 96.57 / 97.06 / 94.64점임
  - 비전: CharXiv, A-OKVQA, OmniDocBench v1.6, RealWorldQA, OCRBench v2에서 78.59 / 81.64 / 79.82점임
- 코딩 에이전트, 도구 사용 시스템, 멀티모달 워크플로, 장기 작업은 작은 오류가 여러 단계에 걸쳐 누적될 수 있어 성능 저하에 민감함
  - Bonsai 2 27B는 이 영역들에서 전체 정밀도 모델 성능의 상당 부분을 유지하면서 메모리 사용량을 줄임
  - 코딩, 비전, 에이전트 도구 사용 능력을 상당히 희생하는 다른 저비트 대안과 비교해 메모리 대비 지능 밀도가 높음
- NVIDIA GeForce RTX 5090에서 Cline을 이용한 코딩 에이전트와 컴퓨터 사용 데모를 공개함
- 로컬에서 코딩 에이전트 반복 작업, 컴퓨터 사용 워크플로, 비공개 문서 분석, 멀티모달 디버깅에 활용할 수 있음
  - 민감하거나 빈도가 높은 작업은 로컬에서 처리하고 필요한 경우에만 클라우드로 넘기는 하이브리드 오케스트레이션도 포함됨
- 개별 벤치마크의 전체 결과와 압축, 평가, 측정 절차는 기술 백서에서 확인 가능함
처리량과 에너지 효율
- Ternary Bonsai 2 27B의 처리량은 NVIDIA GeForce RTX 5090에서 최대 143토큰/초, M5 Max에서 46.8토큰/초임
- RTX 4090에서 토큰당 0.714mWh를 소비하며, 전체 정밀도로 실행하는 8B 모델보다 에너지 효율이 40% 높음
- 높은 처리량은 코딩 보조 도구의 수정/디버깅 반복과 멀티모달 에이전트의 스크린샷, 문서, 도구 호출 처리 속도를 높임
- 에너지 효율 개선은 같은 기기에서 더 많은 추론과 더 긴 배터리 사용 시간을 가능하게 하며, 클라우드를 계속 호출하지 않는 백그라운드 보조 도구의 실현 가능성을 높임
저비트 모델의 배포 효과
- PrismML은 성능 유지율이 95%에서 98% 이상으로 높아진 이번 압축을 실질적으로 “무손실”에 가까운 수준으로 평가함
- 저비트 모델은 로컬 추론뿐 아니라 기기, 워크스테이션, 데이터센터의 비용 구조와 아키텍처를 바꿀 수 있음
  - 같은 메모리 용량에 더 큰 모델을 넣고, 같은 하드웨어에서 더 많은 사용자에게 서비스를 제공할 수 있음
  - 추론당 에너지를 줄이고, 로컬과 클라우드 중 실행 위치를 동적으로 결정하는 하이브리드 시스템을 구현할 수 있음
- 모델의 절대 성능뿐 아니라 주어진 메모리, 연산, 전력 예산 안에서 얼마나 유용한 지능을 제공하는지가 중요함
  - 성능이 계속 향상되는 동시에 자원 요구량이 크게 줄어든다면, 개인 기기부터 대규모 데이터센터까지 모델 배포 범위가 넓어질 수 있음
지원 플랫폼과 공개 범위
- 전용 저비트 커널을 통해 NVIDIA GPU에서는 CUDA로, Mac, iPhone, iPad에서는 MLX로 실행됨
- 모델 가중치는 Apache 2.0 라이선스로 공개됨
