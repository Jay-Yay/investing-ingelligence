- Tencent가 Hy4 flash를 공개함. 약 2,200억 파라미터 중 토큰당 120억 개를 활성화하며, 네이티브 멀티모달과 100만 토큰 컨텍스트를 지원함
- API 요금은 100만 토큰당 입력 0.070달러, 출력 0.281달러로, Hy4보다 크게 낮음
- 하이브리드 어텐션, LatentMoE, Engram으로 KV 캐시를 Hy4의 1/6로 줄이고, 강화학습으로 평균 종단 간 출력 토큰 수를 50% 줄임
- Tencent 내부 WorkIndex 평가에서 전반적인 작업 성능은 Hy4 preview를 소폭 웃돌았으며, 작업당 평균 비용은 Hy4의 1/20을 기록함
- 가중치를 공개했으며, 일상 생산성 작업에 권장함. 장기 소프트웨어 엔지니어링 같은 복잡한 작업에는 지능 상한이 더 높은 Hy4를 계속 권장함
모델 구조와 비용 최적화
- Hy4 flash는 Tencent의 Hy 모델 중 비용 효율이 가장 높은 모델로, 총 2,240억 파라미터에 Engram 파라미터 640억 개가 포함되며 토큰당 활성 파라미터는 120억 개임
  - Hy4와 마찬가지로 네이티브 멀티모달과 100만 토큰 컨텍스트를 지원함
- API 요금은 100만 토큰 기준으로 Hy4보다 낮음
  - 캐시 입력 요금은 Hy4 flash 0.003달러, Hy4 0.042달러임
  - 입력 요금은 Hy4 flash 0.070달러, Hy4 0.834달러임
  - 출력 요금은 Hy4 flash 0.281달러, Hy4 2.501달러임
- 사전학습 구조에 하이브리드 어텐션, LatentMoE와 Engram을 결합해 KV 캐시 크기를 Hy3의 1/24, Hy4의 1/6로 줄임
  - 다양한 규모의 단계별 확장 실험으로 기대 성능 충족 여부를 확인함
- 사후학습에서는 Hy4로부터의 자기 증류로 범용 지능을 확보하고, 강화학습으로 평균 종단 간 출력 토큰 수를 50% 줄임
- 추론에서는 메가커널(megakernel), 4비트 양자화와 DFly를 결합해 초당 150토큰을 넘는 디코딩 속도를 달성하고 대규모 저비용 서빙을 지원함
평가 결과와 사용 범위
- WorkIndex는 일반적인 WorkBuddy 작업에 기반한 내부 벤치마크로, 사람 평가와 함께 결과물 품질, 단일 턴 출력 길이, 작업 완료 시간을 평가함
  - 일상 업무와 동떨어진 공개 벤치마크 점수보다 실제 작업에 초점을 맞춤
  - 8개 평가 세트는 슬라이드 생성, 슬라이드 편집, 사람과 AI의 슬라이드 공동 작성, Markdown 공동 작성, 문서 편집, 스프레드시트 복구, 오디오/비디오 처리, 시각적 이해로 구성됨
  - 별도의 공개 에이전트 벤치마크 묶음에는 DeepSWE, ProgramBench, Terminal-Bench 4.0, APEX-Agents, AutomationBench, HLE, OSWorld 2.1의 7개가 포함됨
- 전반적인 작업 성능은 Hy4 preview를 소폭 웃돌았으며, WorkIndex의 작업당 평균 비용은 비교 모델보다 낮았음
  - Hy4 preview의 1/13, Hy4의 1/20임
  - DeepSeek-V4.1-Flash-1017의 Max 등급 피크 시간대 요금 기준으로는 1/8임
- 내부 WorkBuddy 사용자 85명이 27개 범주의 259개 작업을 수행한 블라인드 평가에서, 사용자 만족도는 Claude Haiku 5.5에 근접함
  - 평가 대상 모델 중 종단 간 완료 시간이 가장 짧았고, 작업당 비용도 다른 모든 모델보다 크게 낮았음
- WorkBuddy 평가에서는 Hy4 대비 약 1/15 비용으로 평균 작업 시간을 70% 줄임
  - 일상 작업 품질은 Hy4와 동등했으며, 장기 코딩 작업에서만 소폭 하락함
- Yuanbao 작업 흐름에서는 Hy3 대비 에이전트 성능이 13.6%, 사람이 결과를 나란히 비교하는 GSB 에이전트 평가 점수가 7.56% 향상됨
  - 작업 완수의 철저함, 정보 전달의 명확성, 출력의 신뢰성과 전문성이 두드러짐
  - 일반 대화 작업에서는 GLM-5.3-Flash보다 2.52% 높은 성능을 보였으며, 특히 다중 턴 대화에서 개선 폭이 컸음
- 권장 용도는 심층 검색, 문서 처리를 비롯해 슬라이드 제작, 간단한 프런트엔드 데모, 컴퓨터 사용 등 대부분의 일상 생산성 작업임
  - 장기 소프트웨어 엔지니어링처럼 복잡한 작업에는 더 높은 지능 상한을 갖춘 Hy4를 권장함
- Tencent Cloud TokenHub, WorkBuddy, Yuanbao, WeCom, QQ, ima, Marvis 등에서 이용 가능하며, OpenRouter에도 출시
  - 11월 30일까지 WorkBuddy에서 무료로 이용할 수 있고, Tencent Cloud TokenHub의 API 요금은 50% 할인됨
- 오픈 웨이트를 GitHub, Hugging Face, ModelScope, AtomGit에 공개함
  - 실제 작업 흐름에서의 유용성과 효율을 개선하기 위해 잦은 업데이트를 계획하고 있으며, Hy4의 가중치도 곧 공개할 예정임
- Plotly의 데이터 분석 평가에서는 43문제 중 39문제를 통과하는 데 0.13달러가 들었음. Hy4는 42문제를 통과하는 데 2.11달러가 들어, 정확도 일부를 양보하면서 비용을 크게 줄임

## 텔레그램 수집 시 유의사항

- 이 컬렉터는 공개 웹 미리보기(t.me/s/{channel})만 수집하며, 비공개 채널 수집은 이 단계에서 구현하지 않는다.
- 웹 미리보기는 페이지당 최대 20개 메시지씩, 최대 10페이지(최근 약 200개)까지만 페이지네이션한다.
- 이미지, 동영상 등 미디어 전용 메시지(텍스트 없음)는 캡처하지 않는다.
- 메시지에 포함된 기사 링크(최대 메시지당 3개, 유튜브/X/인스타그램/페이스북 제외)는 본문을 함께 가져와 아래 '첨부 기사 원문'에 붙인다 - 실패하면 그 링크만 오류로 표시된다.
