### Windows 11 내장 날씨 앱, RAM 1GB 이상 낭비 | GeekNews

(https://news.hada.io/topic?id=32310)

- Windows 11의 Weather 앱은 일기예보만 표시해도 RAM을 1GB 넘게 사용하며, 기본 조작 중에는 최대 1.5~1.6GB까지 늘어남
- 완전한 네이티브 앱이 아닌 WebView2 기반 MSN Weather 웹 앱으로, 여러 Chromium 하위 프로세스를 동시에 실행함
- 메모리 사용량은 약 1GB에서 시작해 유휴 상태에서 500~600MB로 줄지만, 확대나 화면 이동 시 다시 증가하며 macOS Weather의 250MB 미만보다 약 5배 큼
- RAM 8GB PC에서는 앱 하나가 시스템 메모리의 약 20% 를 차지할 수 있어, 8GB·16GB 시스템의 페이지 파일 의존과 반응성 저하로 이어질 수 있음
- 예보 피드에는 날씨 카드처럼 보이는 광고도 삽입돼, 저사양 하드웨어의 효율과 네이티브 앱 확대를 추진한다는 Microsoft의 계획과 어긋남
기본 조작에도 치솟는 메모리 사용량
- Windows Latest의 테스트에서는 별다른 집중적 상호작용 없이 일기예보만 표시하던 Weather 앱이 RAM 1.2GB 이상을 사용함
- Wccftech도 비슷한 동작을 관찰함
  - 실행 초기에는 약 1GB를 사용함
  - 유휴 상태에서는 약 500~600MB로 줄어듦
  - 확대하거나 인터페이스를 이동하는 기본 조작만으로 1.5~1.6GB까지 증가함
- RAM 8GB PC에서는 Weather 앱 하나가 전체 시스템 메모리의 거의 20% 를 차지할 수 있음
- 비슷한 조건에서 macOS의 Apple Weather 앱은 RAM을 250MB 미만 사용해 Microsoft 앱보다 메모리 사용량이 약 5배 적음
WebView2가 만드는 다중 프로세스 구조
- Windows 11 Weather는 완전한 네이티브 Windows 앱이 아니라 MSN Weather 웹 앱을 Microsoft의 WebView2 프레임워크로 감싼 형태임
- 작업 관리자에는 여러 Chromium 기반 하위 프로세스가 동시에 나타나며, 이 구조가 높은 RAM 사용량에 기여함
8GB·16GB 시스템의 메모리 압박
- RAM 32GB 이상의 고사양 PC에서는 높은 메모리 사용량이 큰 영향을 주지 않을 수 있음
- RAM 8GB 또는 16GB 시스템에서는 Weather 실행만으로 메모리 압박이 커질 수 있음
  - Windows가 페이지 파일에 더 많이 의존할 수 있음
  - 그 결과 시스템 반응성이 떨어진다고 느낄 가능성이 있음
예보 카드처럼 삽입된 광고
- Weather 인터페이스에는 스폰서 콘텐츠가 예보 피드에 직접 삽입됨
- 광고는 날씨 카드와 유사한 시각적 형태로 함께 표시됨
- Microsoft는 Foreca, ECMWF와 여러 지역 기상 서비스에서 날씨 데이터를 라이선스하지만, Windows 내장 앱에 광고를 넣은 점은 비판을 받음
Windows 11 효율화 계획과의 간극
- Microsoft는 내장 앱을 업데이트하면서 Windows 11이 저사양 하드웨어에서도 더 나은 성능을 내도록 하겠다고 반복해서 밝혀옴
- Microsoft 임원 Rudy Huyn은 앞으로 완전한 네이티브 Windows 앱을 더 많이 개발할 계획이라고 밝힘
- 다만 Weather를 비롯한 MSN 브랜드 앱이 향후 WinUI로 다시 개발될지는 불분명함
