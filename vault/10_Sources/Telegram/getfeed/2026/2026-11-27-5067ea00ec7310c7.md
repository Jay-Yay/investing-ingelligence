- 1980년대 초부터 현재까지 UI 스타일 가이드 69종을 모은 아카이브. 데스크톱과 모바일 등 여러 플랫폼의 설계 지침을 통해, 시대와 회사별 인터페이스 원칙을 비교해 볼 수 있음
- Apple, Windows, Android의 여러 시기별 지침을 제공하며, 초기 Lisa와 Macintosh부터 Aqua, iOS, Material Design, 현재 공식 가이드까지 포함함
- Amiga, NeXTSTEP, Newton, Palm OS 등 과거 플랫폼뿐 아니라 CDE, OPEN LOOK, SGI 같은 UNIX 환경과 Java의 GUI 설계 문서도 수록함
- 자료는 PDF, 웹사이트 미러, Internet Archive 등의 형태로 제공되며, 일부 플랫폼은 초안과 개정판도 함께 볼 수 있음
- 전체 자료 ZIP 다운로드를 제공하며, 일부 웹 미러는 이미지 표시와 YouTube 삽입 등을 가볍게 수정해 읽기 편하게 정리함
컬렉션의 범위와 이용 방식
- UI 스타일 가이드, 즉 인터페이스 지침을 회사와 플랫폼별로 모았으며, 1980년대 초부터 현재까지의 자료를 포함함
- 문서에 따라 PDF와 웹 미러, Internet Archive 뷰어, Wayback Machine 보관본, 현재 공식 사이트로 접근할 수 있음
- 일부 미러에는 이미지의 픽셀 표현 개선, 링크된 이미지의 본문 삽입, YouTube 삽입 수정 등 가벼운 정리 작업을 적용함
- 전체 스타일 가이드 ZIP을 한 번에 내려받을 수 있음
Amiga, Android, BlackBerry
- Amiga: 1980~1990년대 유럽에서 특히 인기를 끈 Commodore의 멀티미디어 개인용 컴퓨터이며, GUI 이름은 Workbench였음
- Android: iOS와 경쟁하는 모바일 운영체제로, 이 컬렉션에서 찾은 가장 이른 스타일 가이드는 2012년 자료임
- BlackBerry: 휴대기기 제조사로, 핸드헬드, 태블릿, 스마트폰 지침을 수록함
CDE, CUA, GEM/TOS, GNOME
- CDE: UNIX용 데스크톱 환경으로, OSF/Motif 위젯을 사용했으며 이후 OSF/Motif와 통합됨
- CUA: 1980년대 후반의 UI 표준으로, Windows와 OS/2에 영향을 줌
- GEM/TOS: 1980년대 운영체제/GUI로, Atari ST 사용자에게는 TOS로 잘 알려졌음
- GNOME: Linux와 BSD용 데스크톱 환경이며, 지침의 버전 번호 체계가 매우 혼란스러울 수 있음
iOS/iPadOS와 Java
- iOS/iPadOS: 초기 iPhone OS부터 이후 iOS와 iPad의 인터페이스 지침을 포함함
- Java: JFC(Java Foundation Classes)와 Swing GUI 구성요소에 관련된 디자인 지침을 수록함
Lisa와 클래식 Macintosh부터 현대 Mac까지
- 초기 Apple GUI: 1980년 Lisa부터 Apple II와 클래식 Mac OS까지의 지침을 모음
- Mac OS X/Aqua 이후: 초기 Aqua, 발전기의 Aqua, 순수 Aqua와 Liquid Glass 사이 시기를 구분해 자료를 제공함
  - Adopting the Aqua Interface, 2000, 2001년 예비판/정식판, Aqua Human Interface Guidelines, 2002: 초기 Aqua 자료임
  - Apple Human Interface Guidelines, 2004년 5월: 2004년 8월, 2005년 9월/12월, 2006년 5월/10월, 2008년 1월/6월, 2009년판도 수록함
  - OS X Human Interface Guidelines, 2014: 순수 Aqua와 Liquid Glass 사이 시기를 다루며, 2012년과 2013년판도 있음
  - 현재 지침은 Apple Human Interface Guidelines로 연결됨
Magic Cap, Microsoft Office, NeXTSTEP, Newton, Nokia
- Magic Cap: General Magic이 설계했으나 중단된 모바일 운영체제임
- Microsoft Office: 특히 리본 UI 사용을 다룬 제품별 지침을 제공함
- NeXTSTEP: NeXT의 운영체제와 GUI로, 이후 한쪽으로는 OpenStep, 다른 쪽으로는 현대 Mac OS X로 이어짐
- Newton: 1993년에 출시되고 1998년에 중단된 Apple의 PDA임
- Nokia: Symbian을 포함한 초기 스마트폰 스타일 가이드를 수록함
OPEN LOOK, Palm OS, PenPoint, RISC OS
- OPEN LOOK: Sun과 AT&T가 시작한 UNIX GUI임
- Palm OS: Palm 모바일 기기의 초기 그래픽 운영체제로, 이후 회사는 webOS로 전환함
- PenPoint: GO Corporation이 성공하지 못한 자사 기기 제품군을 위해 개발한 초기 태블릿 운영체제임
- RISC OS: 원래 Acorn 컴퓨터용으로 개발한 영국의 운영체제와 GUI이며, 커뮤니티 프로젝트로 이어지고 있음
Samsung, Silicon Graphics, Taligent, webOS
- Samsung: Gear, One UI, 스마트 TV의 디자인 지침을 포함함
- Silicon Graphics: SGI의 UNIX 기반 운영체제용 스타일 가이드를 수록함
- Taligent: Apple과 IBM의 합작으로 설립된 소프트웨어 회사이며, 결과물 중 하나가 CommonPoint 애플리케이션 프레임워크였음
- webOS: Palm OS의 후속 운영체제로, HP와 이후 LG Electronics에 인수됐으며 현재 스마트 TV, 냉장고, 프로젝터에 사용됨
Windows와 Windows Phone
- Windows: 초기 SDK 스타일 가이드부터 Windows 8/10과 현재 앱 디자인 지침까지 수록함
- Windows Phone: Windows Mobile 6부터 Windows Phone 7까지, 성공하지 못한 모바일 Windows 계열의 지침을 모음
