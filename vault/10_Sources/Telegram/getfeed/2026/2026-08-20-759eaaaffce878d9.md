- Linear 유료 고객의 제품 개발 흐름을 분석한 결과, 2026년 상반기 AI 기능 사용률이 모든 직군에서 2배 이상 증가했으며 기업 규모와 관계없이 확산됨
- AI는 기존 업무를 줄이기보다 그 위에 더해짐. 이슈 작성·분류·댓글 시간은 대체로 늘고 기획 시간은 유지된 가운데 AI 채팅과 에이전트 위임이 새로운 업무로 등장함
- AI가 작성한 이슈는 2024년 1,000건당 1건 미만에서 2026년 8월 전체의 절반 가까이로 늘었고, PR 첨부 비율도 제품 직군은 3%에서 10%, 디자인은 1%에서 8%로 상승함
- 팀당 주간 Pull Request(PR) 수는 2024년 6월 대비 111% 증가함. 코딩 에이전트 연결 팀은 주당 21개에서 65개로 늘어난 반면 미연결 팀은 8개에서 10개로 증가함
- PR 증가는 AI 도입과 개발 가속의 강한 상관관계를 보여주지만 사업 성과나 코드 가치까지 입증하지는 못함. 관측 범위에서는 AI가 시간을 절약하기보다 개발 활동을 확대함
분석 범위와 한계
- Linear에서 매일 소프트웨어를 만드는 수만 개 팀의 6년간 데이터를 바탕으로, AI가 널리 도입되기 전부터 2026년까지 제품 개발 흐름을 분석함
- 토큰 사용량이나 코드 분량이 아니라 첫 이슈부터 이를 종료하는 Pull Request(PR) 까지 전체 작업 흐름을 관찰함
- Linear 내부에서 확인되는 활동만 대상으로 삼으므로 외부 AI 사용은 포함되지 않으며, 전체 시장이 아닌 Linear 고객 기반의 도입 양상을 나타냄
- 분석 축은 AI를 사용하는 사람, Linear에서 직무별 시간 배분이 달라진 방식, 실제 산출량 변화의 세 가지임
직군과 기업 규모를 가리지 않은 확산
- 2026년 1월부터 6월까지 최근 30일 내 Linear AI 기능을 사용한 비율이 모든 직군에서 2배 이상 증가함

  - 엔지니어링: 12%→30%, +18%p
  - 창업자: 14%→30%, +16%p
  - 디자인: 6%→22%, +16%p
  - 시장 진출(GTM): 5%→18%, +13%p
- 직함을 정규화해 직무를 분류했기 때문에 경계 사례에는 오차가 있지만, 확산 양상은 분류 오류만으로 보기 어려울 만큼 광범위함
- 해당 비교는 2026년 1월과 6월에 모두 활동한 유료 사용자 12만7,000명을 대상으로 함
- 기업 규모별 사용률도 약 3배로 증가해, 신기술 도입 속도에 흔히 영향을 주는 조직 규모가 거의 변수로 작용하지 않음

  - 51~200명: 9%→25%
  - 1~50명: 8%→23%
- 기업 규모가 확인되고 두 기간 모두 활동한 유료 사용자 19만9,000명이 분석에 포함됨
경영진의 직접 사용 증가
- 경영진도 소속 팀과 비슷하거나 더 높은 비율로 AI를 직접 사용함
- 직원 201명 이상 기업의 CEO 사용률은 6개월 동안 9%에서 36% 로 27%p 상승해 전체 분석 항목 중 가장 큰 증가 폭을 기록함
- 다른 주요 변화도 최고경영진 전반에서 나타남
  - 201명 이상 기업 CTO: 11%→35%
  - 201명 이상 기업 CPO: 3%→24%
  - 1~50명 기업 CPO: 11%→36%
  - 1~50명 기업 창업자: 15%→31%
- 최고위 리더도 AI를 간접적으로 접하는 데 그치지 않고 직접 사용하며 익히는 흐름을 보임
- 기업 규모는 제3자 데이터로 보완했기 때문에 다른 항목보다 적은 워크스페이스가 포함됐으며, 표본은 두 기간 모두 활동한 경영진 1만3,300명임
기존 업무 위에 더해진 AI 작업
- 2025년 6월부터 2026년 6월까지 이슈 생성·분류·할당·업데이트·댓글 시간이 거의 모든 직군에서 증가함
  - 엔지니어링의 생성·분류 시간은 월 24분에서 28분으로 약 17% 증가했고, 댓글은 35분에서 40분으로 늘어남
  - 창업자는 생성·분류가 40분에서 57분, 댓글이 39분에서 64분으로 각각 17분과 26분 증가했지만 표본이 작아 변동성이 더 큼
  - 제품 직군의 생성·분류는 38분에서 37분으로 1분 줄었고, 할당·업데이트는 26분으로 동일함
- 작업량이 늘수록 더 많은 조율이 필요하며, 이 조율 정보는 에이전트가 행동하는 데 필요한 맥락으로도 활용됨
- 고객 요청, 문서, 프로젝트에 쓰는 기획 시간은 같은 기간 거의 달라지지 않음
  - 제품 직군의 문서·프로젝트 시간은 월 13분에서 14분, 고객 요청은 3분에서 4분으로 소폭 증가함
  - 팀마다 기획 방식이 크게 다르고 실제 기획의 상당 부분은 대화에서 이뤄지므로, 평균에는 기획 활동이 많은 팀과 적은 팀이 함께 포함됨
- 기획 시간의 안정성은 AI가 무엇을 만들지 결정하는 과정보다 실행 방식을 더 크게 바꿨음을 보여줌
- 1년 전에는 없었던 에이전트 이슈와 AI 채팅이 모든 직군의 업무에 새로 등장함
  - AI 채팅은 제품 직군 월 5분, 창업자 4분, 디자인·GTM 3분, 엔지니어링 2분으로 제품 직군에서 가장 많음
  - 에이전트 이슈는 창업자 2분, 엔지니어링·제품 직군 1분이며 디자인과 GTM은 0분으로 집계됨
- 다른 활동 시간이 줄지 않았기 때문에 현재까지 AI 업무는 기존 작업을 대체하기보다 추가 계층으로 자리 잡음
- 시간 비교 표본은 2025년 6월 유료 사용자 5만4,300명과 2026년 6월 8만9,000명임
AI가 작성하는 이슈의 급증
- 2년 전 AI가 만든 이슈는 1,000건당 1건 미만이었지만, 2026년에는 Linear에서 생성되는 이슈의 절반 가까이를 AI가 작성함
- Agents 및 MCP 클라이언트가 만든 주간 이슈는 2024년 6월 사실상 0건에서 2026년 8월 3일 주간 243만5,000건으로 증가함
- 같은 주 사람과 통합 기능이 만든 이슈는 248만1,000건으로, AI 생성량이 사람과 통합 기능의 합계에 근접함
- 2026년 7월 27일 주간에는 AI가 234만8,000건, 사람과 통합 기능이 235만7,000건을 생성함
- 이 추세가 이어지면 AI가 사람과 통합 기능을 합친 것보다 더 많은 이슈를 작성하게 됨
- 가져온 이슈는 집계에서 제외함
비개발자의 코드 기여와 PR 증가
- 연결된 저장소의 PR을 최근 30일 내 첨부한 사용자 비율이 2024년 6월부터 2026년 6월까지 모든 직군에서 상승함
  - 엔지니어링: 20%→34%
  - 창업자: 11%→23%
  - 제품: 3%→10%
  - 디자인: 1%→8%
  - GTM: 1%→3%
- Linear에 연결된 저장소의 PR만 집계하므로 외부에서 코드를 배포한 활동은 보이지 않으며, 이 비율은 실제 수준의 하한선임
- 이전에는 변화를 기술하던 제품·디자인 직군이 점차 직접 코드를 제출하는 흐름을 보임
- 2026년 6월 기준 PR 첨부 분석 표본은 유료 사용자 16만6,000명임
- 유료 워크스페이스당 주간 PR 수는 2024년 6월 기준선보다 111% 증가함
  - 첫해에는 대체로 비슷한 수준을 유지했지만, 모델 품질과 도입률이 함께 상승한 2026년부터 증가세가 가팔라짐
  - 2026년 6월 7일 +106%, 6월 14일 +113%, 6월 21일 +111%를 기록함
- 집계 대상은 병합된 PR이 아니라 열린 PR이며, PR 개수만으로 변경의 가치를 판단할 수 없음
- PR 변화 분석에는 2026년 6월 기준 유료 워크스페이스 4만7,900개가 포함됨
코딩 에이전트와 산출량 가속
- 코딩 에이전트를 연결한 팀의 주간 평균 PR은 2024년 6월 21개에서 2026년 6월 65개로 약 3배 증가함
- 미연결 팀은 같은 기간 8개에서 10개로 늘어 증가 폭이 작았으며, 전체 성장의 대부분은 에이전트 연결 팀에서 발생함
- 다만 코딩 에이전트 연결 팀은 에이전트가 등장하기 전부터 PR 산출량이 더 높았으므로 두 집단의 절대 수준을 직접 비교할 수 없음
- 각 집단을 자체 기준선과 비교하면 에이전트 연결 팀의 증가세가 뚜렷함
- 고정 코호트는 유료 팀 6,887개로, 코딩 에이전트 연결 팀 4,280개와 미연결 팀 2,607개로 구성됨
산출량과 가치 사이의 간극
- 지난 2년간 코딩 에이전트 사용 팀의 산출량 증가는 AI 도입과 개발 가속 사이의 명확한 상관관계를 보여주지만, 긍정적인 사업 성과로 이어졌는지는 확인할 수 없음
- 최고위 리더가 실무형 개별 기여 업무를 더 많이 수행하고 비개발자가 코드를 커밋하면서, 조직 내 역할 경계가 흐려지고 더 많은 사람이 직접 만드는 쪽으로 이동함
- 기존 작업 시간은 유지된 채 AI 사용 시간이 추가됐으므로 관측 범위에서는 제품 개발에 쓰는 총시간이 감소하지 않고 증가함
- AI가 효율을 높여 사용량과 전체 활동을 오히려 확대한다는 점에서 토큰 소비를 넘어선 제번스 역설(Jevons paradox) 의 성격을 보임
- PR은 가치보다 활동량을 나타내지만 토큰 사용량보다는 실제 개발 흐름에 가까운 지표임
  - 기계적인 리팩터링은 많은 토큰을 쓸 수 있지만 중요한 버그 수정이나 코드 리뷰는 적은 토큰으로도 가능해, 토큰 지출과 가치가 일치하지 않음
- 향후에는 Linear를 거치는 코드와 코드 리뷰를 활용해 토큰 지출부터 실제 결과까지 전체 작업 생명주기를 분석할 계획임
측정 방법과 용어
- AI 대화, 에이전트 세션, 이슈 활동, 댓글, PR을 포함한 Linear의 집계 제품 데이터를 사용하며, 개인 행동이 아닌 광범위한 사용 패턴을 분석함
- 유료 워크스페이스와 사용자만 포함하고, 각 지표는 한 달 또는 최근 30일의 고정 기간으로 측정함
- 연간 비교에는 2025년 6월과 2026년 6월을 사용하고, 도입률은 이동식 30일 구간, 시계열은 주간 단위로 집계해 단기 변동을 줄임
- 일부 차트는 비교 기간 양쪽에서 모두 활동한 사용자만 포함함
- AI-active는 28일 동안 앱 또는 Slack에서 AI 대화나 에이전트 세션을 한 번 이상 사용한 사용자를 뜻함
- Agent team은 코딩 에이전트가 연결된 워크스페이스임
- Pull request는 Linear 연결 저장소에 대해 열린 코드 변경이며 병합 여부는 집계하지 않음
- Paid workspace는 해당 기간에 활동한 유료 플랜 워크스페이스임
- Agent issue는 이슈를 에이전트에 위임하거나 세션을 시작한 활동임
- Company size는 제3자 보완 데이터에서 얻은 회사의 정규직 직원 수임

## 텔레그램 수집 시 유의사항

- 이 컬렉터는 공개 웹 미리보기(t.me/s/{channel})만 수집하며, 비공개 채널 수집은 이 단계에서 구현하지 않는다.
