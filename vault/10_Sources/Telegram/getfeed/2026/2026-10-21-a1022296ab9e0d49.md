### 광고 없는 Android TV 만들기 | GeekNews

(https://news.hada.io/topic?id=35697)

- 홈 화면과 YouTube 앱을 교체해, Android TV의 홈 배너와 YouTube 광고를 없애는 방법
- Projectivy Launcher로 원하는 앱만 표시하고, SmartTube로 광고와 영상 내 협찬 구간을 건너뛰도록 구성
- Button Mapper로 리모컨의 YouTube 버튼을 SmartTube에 연결하고, Jellyfin 영상 재생에는 Wholphin 사용
- ADB로 기본 런처와 앱을 변경하며, Chromecast 2대와 Hisense TV에서 사용한 설정과 복구 방법 제공
- 추가로 Pi-hole이나 AdGuard DNS를 이용해 광고와 추적 도메인을 차단하는 방법 소개
홈 화면과 영상 앱 교체
- Google TV는 앱 전용 모드에서도 상단 홍보 배너가 남으며, 기본 설정에 런처 변경 옵션이 없음
- Projectivy Launcher 로 홈 화면을 원하는 앱만 표시하도록 교체
  - 대안으로 FLauncher와 ATV Launcher Pro 소개
- SmartTube 로 YouTube를 시청하며, 내장된 SponsorBlock으로 영상 내 협찬 구간도 건너뛰기
  - 개발자는 인터페이스 때문에 SmartTube를 선호하며, 크리에이터 지원을 위해 YouTube Premium 구독도 유지
- Button Mapper 로 리모컨의 YouTube 버튼을 SmartTube에 연결
- 개인 미디어 서버인 Jellyfin의 클라이언트는 UI와 맞춤 설정을 이유로 Wholphin 을 선택. 대안으로 Moonfin 소개
설치와 설정의 핵심
- 개발자 옵션에서 디버깅을 활성화하고 ADB 로 연결해 설정
  - Projectivy와 Wholphin, Button Mapper는 Play Store에서 설치
  - SmartTube는 GitHub의 APK를 ADB로 설치하거나 Downloader로 사이드로딩
- Projectivy를 홈 앱으로 먼저 지정한 뒤 기본 런처를 비활성화해야 함
  - 일부 기기는 이 과정에서 저장된 Wi-Fi 연결 정보가 사라질 수 있음
  - TV의 HDMI 입력 전환이 정상 작동하는지도 확인
- Button Mapper와 Projectivy의 접근성 서비스를 활성화하고 리모컨 버튼을 설정
  - ADB로 접근성 서비스 목록을 변경할 때는 기존에 사용하던 서비스도 보존
- 비활성화한 앱은 adb shell pm enable <package> , 사용자 계정에서 제거한 내장 앱은adb shell cmd package install-existing <package> 로 복구 가능
- 작업이 끝나면 무선/USB 디버깅을 끔. 구체적인 명령과 기기별 연결 방법은 원문에 제공
DNS 차단과 추가 정리
- Pi-hole 로 집 안 기기의 광고와 추적 도메인을 차단하거나, TV의 Private DNS를 AdGuard DNS 로 설정 가능
- 기본 런처를 유지하면서 androidtvwatsonfe-pa.googleapis.com 을 차단하면 배너를 숨길 수 있다는 작동 보고도 소개
  - 기기 재시작이나 런처 캐시 삭제가 필요할 수 있음
- 사용하지 않는 제조사 앱과 광고 서비스를 더 정리하려면 cleanyourtv의 기기별 목록 참고
- 실제 설정한 기기는 Google TV 탑재 Chromecast 2대와 Hisense TV이며, 다른 Android TV 기기의 동작을 모두 확인한 것은 아님
