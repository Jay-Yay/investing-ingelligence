### AMD, 모델을 실리콘에 새기는 AI 칩 스타트업 Taalas 인수 | GeekNews

(https://news.hada.io/topic?id=32224)

- AMD가 모델 가중치를 실리콘에 직접 새기는 Taalas를 인수해 Nvidia가 주도하는 고성능 추론 시장 공략을 강화함
- TSMC 6nm 공정의 모델 전용 칩 HC1은 Meta Llama 3.1 8B를 초당 16,960토큰으로 처리해 발표 당시 Nvidia GPU보다 48배, Cerebras 가속기보다 8.5배 빨랐음
- 2세대 HC2는 칩당 200억 파라미터를 목표로 하며, 파이프라인 병렬화로 가중치를 분산하면 가속기 50개로 1조 파라미터 모델을 지원할 수 있음
- AMD는 Instinct 기반 Helios 랙에서 GPU가 연산량이 큰 프롬프트 처리를, Taalas 기반 가속기가 토큰 생성을 맡는 분리형 구성을 고려하고 있음
- 모델 배포 후 LoRA 어댑터보다 큰 변경에는 칩 재제작이 필요하지만, 토큰 비용을 낮추고 출력 속도를 10~20배 높인다면 더 긴 추론을 사용하는 테스트 시간 스케일링의 활용 범위가 넓어질 수 있음
AMD의 Taalas 인수
- AMD는 AI 하드웨어 시장에서 Nvidia와 경쟁하기 위해 2023년 토론토에서 설립된 Taalas를 인수함
- 인수 조건은 공개하지 않았으며, 인력만 확보하는 인재 인수가 아니라 회사 자체를 인수하는 거래로 파악됨
- 고성능 프리미엄 추론 서비스를 더 빠르고 저렴하게 운영한다는 점에서 Nvidia가 Groq와 체결한 200억 달러 라이선스 계약과 비슷한 맥락임
  - 코드 도우미 같은 AI 에이전트 서비스가 주요 적용 대상임
- 거래는 규제 승인을 거쳐 2026년 4분기에 마무리될 예정임
모델 전용 집적회로의 구조
- Taalas는 HBM에 모델 가중치를 저장하는 대신 실리콘에 직접 새김
- 기존 GPU는 물론 Groq LPU와 Cerebras 웨이퍼 스케일 가속기의 데이터 흐름 구조와도 다른 접근임
- 칩은 사실상 모델 전용 집적회로(MSIC)이며 크게 두 영역으로 구성됨
  - mask-ROM recall fabric에는 모델 가중치를 새김
  - SRAM recall fabric에는 KV 캐시와 미세조정 어댑터를 저장함
- 구체적인 내부 작동 방식은 대부분 공개되지 않았음
HC1의 개념 검증 성능
- Taalas가 2026년 2월 공개한 첫 시험 칩 HC1은 TSMC 6nm 공정으로 제작됨
- 레티클 크기의 HC1은 Meta Llama 3.1 8B를 초당 16,960토큰으로 처리함
  - 발표 당시 Nvidia GPU보다 48배 빨랐음
  - Cerebras 가속기보다 8.5배 빠른 수준임
- Llama 3.1은 2024년 중반 공개된 모델이지만, HC1은 최신 모델 지원보다 기술의 개념 검증을 목적으로 삼았음
HC2와 대규모 모델 확장
- 2026년 여름 출시 예정인 2세대 HC2는 칩당 200억 파라미터 지원을 목표로 함
- 더 큰 모델은 GPU와 마찬가지로 파이프라인 병렬화를 이용해 여러 가속기에 가중치를 분산함
- 칩당 200억 파라미터라면 가속기 50개로 1조 파라미터 모델을 지원할 수 있음
- AMD는 이 구성을 수용할 랙 규모 컴퓨팅 플랫폼과 자체 시스템 설계팀을 보유함
- 같은 규모의 모델을 서비스할 때 Nvidia LPX 시스템에는 GPU 수십 개와 최소 2,000개의 Groq LPU가 필요해 Taalas 방식보다 공간·전력 효율이 낮음
Instinct 및 Helios와의 결합
- AMD는 Taalas 기술 기반 칩을 Instinct 기반 Helios 랙과 결합하려 함
- 이 구성은 작업별 연산을 분리하는 아키텍처를 시사함
  - GPU는 연산량이 많은 프롬프트 처리를 담당함
  - Taalas 기반 가속기는 토큰 생성을 맡음
- 고객이 먼저 Instinct 가속기에서 모델을 배포·검증하고, 안정화된 모델을 Taalas 가속기로 옮기는 순환 방식도 가능하지만 구체적인 계획은 아직 확인되지 않았음
- AMD는 AI 작업별로 적합한 연산 수단을 선택할 수 있는 풀스택 AI 플랫폼 구축을 추진함
모델 고정에 따른 제약
- 가중치를 실리콘에 새기므로 칩을 배포한 뒤에는 해당 모델에 종속됨
- LoRA 어댑터 수준을 넘어서는 변경에는 칩 재제작이 필요해 비용과 시간이 듦
- 새로운 모델이 거의 매달 등장하는 상황에서 고객은 장기간 사용할 모델을 신중하게 골라야 함
- 다만 새 모델을 적용할 때 칩 전체를 처음부터 다시 설계할 필요는 없음
  - Taalas에 따르면 금속층 2개만 변경하면 돼 전체 재설계보다 비용과 시간이 적게 듦
예상 고객과 적용 가능성
- 모델 고정 비용을 감당할 수 있는 AI 모델 개발사, 인프라 제공업체, 일부 추론 서비스 사업자가 주요 사용처가 될 가능성이 큼
- Taalas는 모델 가중치를 실리콘에 새기는 비용이 프런티어 모델 훈련보다 100배 저렴하다고 밝힘
- OpenAI, Anthropic, Meta는 모두 AMD Instinct의 주요 고객임
- 이들 모델 개발사와 AMD의 협력 관계를 고려하면 GPT나 Claude가 Taalas와 Instinct 가속기 조합에 배포될 가능성도 있으나, 확정된 계획은 없음
추론 비용과 테스트 시간 스케일링
- 테스트 시간 스케일링(test-time scaling)은 모델이 응답하기 전에 더 오래 생각하게 해 시간과 정확성을 교환하는 방식임
- 더 많은 토큰을 소비하므로 비용이 커지고 챗봇·코드 도우미·에이전트의 응답 대기 시간도 길어짐
- Taalas 기술이 토큰당 비용을 낮추고 출력 속도를 10~20배 높인다면 모델 개발사는 추론 시간을 더 길게 확장할 수 있음
- 빠르고 저렴한 토큰 생성은 서비스 처리량뿐 아니라 더 많은 추론 토큰을 사용하는 모델 개발 방식에도 영향을 줄 수 있음
