## 첨부 기사 원문

### 67센트로 1.5시간 학습한 소형 Transformer, ARC-AGI-1에서 여러 LLM | GeekNews

(https://news.hada.io/topic?id=33126)

- RTX 5090 한 장에서 소형 Transformer를 처음부터 학습해 ARC-AGI-1 44%, ARC-AGI-2 7% 를 기록했으며, 전체 학습과 추론에 1.5시간과 67센트가 들었음
- 입력·출력 격자를 토큰화하고 과제별 임베딩, 3D RoPE, 색상·이면체 변환 증강을 결합해 여러 퍼즐을 함께 학습하며, 테스트 출력으로 가장 빈번한 후보 2개를 제출함
- SwiGLU·RMSNorm·8개 계층·NorMuon·가변 길이 FlashAttention을 도입하고 손실을 출력 토큰에만 적용해 ARC-AGI-1 점수를 약 40%에서 44%로 높이면서 증강과 비용을 줄임
- 3D RoPE나 과제별 임베딩을 제거하면 점수가 각각 약 24%로 떨어졌으며, 여러 실행에서 해결한 과제의 합집합은 55% 여서 같은 Transformer 체계로 65%에 도달할 여지가 있다고 봄
- 검증 손실은 나빠졌지만 실제 점수는 높아진 결과가 소규모 데이터에서 최저 검증 손실만 추구하는 방식의 한계를 드러내며, 공개된 코드로 점수 향상·비용 절감·데이터 증강 제거를 실험할 수 있음
표본 효율성을 위한 ARC-AGI 선택
- 목표는 오늘날 AI의 핵심 문제로 보는 표본 효율성을 개선하는 것임
  - 현재 Transformer와 딥러닝 방식으로 달성할 수 있는 표본 효율성의 한계를 확인함
  - 반복 실험을 빠르고 저렴하게 수행할 수 있도록 비용을 낮춤
  - 이후에는 이 한계를 넘기 위한 새로운 연구 아이디어를 시험할 계획임
- ARC는 표본 효율성을 시험하기에 적합한 특성을 가짐
  - 고차원 공간에 퍼즐이 약 1,000개뿐임
  - 퍼즐마다 규칙은 다르지만 공통 개념을 공유하는 메타학습 벤치마크임
  - 평가 세트에 필요한 개념이 훈련 세트에도 있어 필요한 사전 지식이 적음
  - 사람에게는 매우 쉽고 컴퓨팅 자원이 부족한 연구자도 접근할 수 있음
  - 대량의 합성 데이터나 사람이 설계한 귀납 편향을 사용하는 방법을 제외하면 데이터 효율성 측면에서 아직 포화되지 않음
모델과 학습 방식
- 각 입력·출력 쌍을 토큰 시퀀스로 바꾸고 소형 Transformer가 이를 자기회귀 방식으로 학습함
  - 모델은 테스트 시점에 초기 상태부터 학습됨
  - 훈련 퍼즐과 평가 퍼즐을 함께 사용하지만 평가 퍼즐의 테스트 출력 정답은 숨김
- 퍼즐 간 학습을 가능하게 하도록 각 퍼즐에 별도의 학습 가능한 과제별 가산 임베딩을 부여함
- 각 시퀀스에 2개의 2차원 격자가 있으므로 위치 정보에는 3D RoPE 임베딩을 사용함
- 색상 순열과 이면체(dihedral) 변환으로 시퀀스를 증강함
  - 추론에서도 테스트 입력을 변환한 뒤 출력에 역변환을 적용함
  - 가장 자주 생성된 출력 2개를 제출하는 AAIVR 방식을 사용함
- 구현과 실험 코드는 mdlARC에 공개됨
이전 모델에서 달라진 요소
- 점수 향상에 가장 크게 기여한 변경은 현대적인 아키텍처, 데이터 다양성, 규모 확장임
  - GELU 대신 SwiGLU를 사용함
  - LayerNorm 대신 RMSNorm을 적용함
  - 데이터를 더 다양하게 구성하고 셔플 방식을 개선함
  - 계층 수를 4개에서 8개로 늘림
- 비용 절감에는 다음 변경이 크게 작용함
  - 더 적은 데이터 증강으로도 학습하도록 표본 효율성을 높임
  - AdamW를 NorMuon 중심 구성으로 교체함
  - 훈련에는 가변 길이 FlashAttention, 추론에는 FlexAttention 커널을 사용함
- 입력 토큰에 대한 학습을 제거하고 출력 토큰만 손실에 포함하는 지도학습 방식으로 전환함
  - ARC-AGI-1 점수가 약 40%에서 44%로 개선됨
  - 개선 원인은 확인되지 않았으며 제한된 모델 용량이 한 가지 가능성으로 거론됨
- ARC-AGI-2의 비중복 과제를 추가해 훈련 데이터를 늘림
  - ARC-AGI-2에는 ARC-AGI-1 퍼즐 773개와 신규 퍼즐 347개가 있음
  - ARC-AGI-1 평가 퍼즐 상당수가 반복되므로 ARC-AGI-2를 그대로 학습하면 데이터 누출로 100%에 도달할 수 있음
  - 반복된 773개 퍼즐을 필터링해 누출을 방지함
  - 추가 데이터를 제거해도 약 40%를 기록하지만 계산량은 약 2배 필요함
손실과 최종 점수가 엇갈린 현상
- 입력 토큰 학습을 제거한 뒤 테스트 손실은 나빠졌지만 점수는 상승함
  - 실행 간 점수 편차도 줄어 더 안정적으로 동작함
  - 소규모 데이터에서 최저 검증 손실을 목표로 표본 효율성을 개선하는 방식에는 이런 실패 모드가 있을 수 있음
- 비지도학습 형태가 더 적합한 상황도 있을 수 있어 별도로 평가 중임
- AdamW에서 기본 Muon으로 바꿨을 때는 학습 속도가 빨라졌지만 후반 손실과 점수가 정체됨
  - 후반에 모멘텀이나 학습률을 크게 낮추면 개선됐지만 수동 조정을 피하고자 함
  - NorMuon으로 전환한 뒤 이 문제가 사라짐
절제 실험으로 확인한 기여도
- 성능에 가장 크게 기여한 요소는 3D RoPE와 과제별 임베딩으로 구성된 표현 방식임
- 입력 토큰까지 학습하면 점수가 약 39% 로 낮아짐
- 훈련 데이터를 ARC-AGI-1과 ConceptARC로 제한하면 약 40% 로 비슷함
- 3D RoPE를 1D RoPE로 바꾸면 약 24% 로 하락함
- 과제별 임베딩을 제거해도 약 24% 로 떨어짐
- CompressARC처럼 과제별로 처음부터 비지도학습하면 약 18%, 지도학습하면 약 15%를 기록함
- 증강이나 합성 데이터가 없어도 상당한 성능이 유지돼 순수 Transformer 체계의 잠재력이 예상보다 컸음
공개 코드로 시도할 개선 방향
- 여러 실행에서 해결된 과제의 합집합은 55% 였고, 거의 해결된 과제도 있어 65%에는 큰 변경이 필요하지 않을 것으로 봄
- 개선 아이디어는 다음과 같음
  - RoPE가 위치와 콘텐츠 정보를 섞어 성능을 떨어뜨릴 수 있으므로 PoPE 또는 새로운 위치 임베딩을 시험함
  - 아키텍처를 추가로 현대화함
  - 수제 GPU 코드로 비용을 최대 10분의 1 수준까지 줄임
  - 추가 훈련 데이터 없이 점수를 높이거나 비용을 낮춤
- 데이터 증강을 제거하면서도 낮은 훈련 비용을 유지하는 것이 중요한 과제로 남음
- 단일 Transformer만으로 약 45%에 도달했고 비용과 FLOPS도 낮아, 같은 체계에서 65% 달성이 가능하다고 판단함
테스트 시점 학습을 둘러싼 비판
- 평가 퍼즐을 학습하는 것이 곧 정답을 학습하는 테스트 데이터 학습(training on test) 이라는 비판은 구분이 필요함
  - 테스트 데이터의 정답 라벨을 학습해야 테스트 데이터 학습에 해당함
  - ARC에서 라벨은 평가 퍼즐 테스트 쌍의 출력 격자이며 이번 학습에는 사용되지 않음
  - 평가 퍼즐의 예제 쌍에서 학습하는 것은 메타학습 벤치마크의 일부임
- 평가 입력을 사용하는 방식은 전이적 추론(transductive reasoning))에 해당함
  - 훈련 퍼즐에서 평가 퍼즐로 학습하는 단계와 평가 퍼즐의 예제 쌍에서 테스트 쌍으로 학습하는 단계 모두 전이적으로 구성할 수 있음
  - 새 44% 결과에서는 입력 토큰 학습이 오히려 성능을 낮춰 제거됨
- 테스트 정책의 “응시자는 시험 내용을 미리 알아서는 안 된다”는 문구는 AI가 아니라 시스템을 설계하는 인간을 대상으로 함
  - 평가 세트에 맞춘 귀납 편향 설계를 막기 위한 규정임
  - ARC 커뮤니티에서는 테스트 시점 학습이 허용되고 장려돼 왔음
- 67센트는 사전학습을 제외한 추론 가격이 아니라 모델 초기화부터 전체 과제 추론까지 포함한 평생 계산 비용임
  - Vast.ai에서 RTX 5090을 약 2시간 사용하는 가격을 기준으로 함
모든 테스트 과제를 함께 학습하는 방식의 한계
- 모든 평가 과제를 한꺼번에 학습하는 방식은 현실에서 드물다는 비판에는 타당성이 있음
  - 현실에서는 전체 문제 세트를 동시에 받는 경우가 드물고 사람은 보통 한 문제씩 처리함
  - 다만 사람이 갖지 못한 능력이라는 이유만으로 AI의 해당 능력을 무효화할 수는 없다고 봄
- 과제당 비용은 공동 학습 비용을 평가 과제 수로 나눠 훈련 비용을 상각하므로 다른 모델과의 비교가 불공정할 수 있음
  - ARC 주최 측은 모든 모델에 같은 계산법을 사용하며 TRM도 전체 테스트 과제를 함께 학습함
  - 이번 비용은 학습과 추론을 모두 포함하지만 LLM 기반 방법은 사전학습·오프라인 학습 비용을 제외하는 경우가 있음
- 비교 방식은 다음과 같이 수정함
  - 과제당 비용 대신 전체 평생 계산 비용을 공개함
  - 비교 대상을 TRM·HRM·CompressARC로 제한함
  - 학습 방식이 비슷한 절제 실험을 추가함
ARC-AGI 벤치마크에 대한 평가
- ARC는 유동 지능을 시험하며, 유동 지능은 AGI에 필요하지만 충분조건은 아님
  - ARC-AGI-1이나 ARC-AGI-2를 해결해도 AGI 달성을 뜻하지 않음
  - 벤치마크는 연구해야 할 질문을 찾는 데 목적이 있음
- 목표가 계속 이동했다는 비판과 달리 ARC-AGI-1은 LLM 이전에 나왔고, ARC-AGI-2는 ChatGPT 이전에, ARC-AGI-3는 ARC-AGI-2 포화 이전에 발표됨
- ARC는 표본 효율성을 시험할 수 있고 GPU 자원이 부족한 연구자도 접근 가능한 메타학습 벤치마크임
- ARC-AGI-1·2에서는 합성 데이터 사용을 금지해야 한다고 봄
  - 상위 점수 다수가 대량의 합성 데이터에 의존함
  - 합성 데이터는 퍼즐을 푸는 데 필요한 유동 지능의 기준을 낮춤
  - 모델 제출 후 처음부터 학습하도록 오프라인 학습과 사전학습을 금지하면 합성 데이터 사용을 막고 모델 간 비교를 공정하게 할 수 있음
- 단일 리더보드에서 서로 다른 유형의 모델을 비교하면 세 가지 문제가 생김
  - 비용 축이 온라인 과제당 비용만 계산해 LLM의 대규모 사전학습 비용을 제외함
  - 전체 테스트 과제를 함께 학습하는 mdlARC·TRM·HRM에는 과제 수로 비용을 나누는 방식이 부적절함
  - 공개 퍼즐의 정답이 인터넷에 있으므로 LLM의 공개 평가 점수는 비교 가치가 낮음
- 모델 유형별로 분리된 차트가 필요함
- 테스트 정책 문구도 테스트 시점 학습을 둘러싼 혼란이 없도록 개선할 필요가 있음
다른 ARC 접근법에 대한 비판
- HRM·TRM의 성과를 재귀 루프와 깊은 감독의 효과로 단정하기에는 절제 실험이 부족함
  - 재귀 없이 같은 수준의 성능을 달성할 수 있음
  - 확인된 재귀의 이점은 메모리 이동량을 늘리지 않고 계산량을 확대할 수 있다는 점임
- TRM이 7M 모델로 홍보됐지만 학습되는 임베딩 가중치는 O(100M+) 규모라는 문제가 있음
  - 최소한 7M 활성 가중치라고 불러야 하며 HRM에도 같은 문제가 있다고 봄
- LLM 기반 ARC 접근은 ARC-AGI-1·2에서 새로운 능력을 보여주기 어려워졌다고 판단함
  - 점수 상승이 주로 사후학습과 합성 데이터 양에 의해 발생할 수 있음
  - 모델별 학습 데이터 차이 등 혼란 변수가 많음
  - 공개 퍼즐 정답이 인터넷에 있으므로 LLM은 비공개 점수만 유효하다고 봄
  - 프런티어 연구소가 사후학습과 하네스를 직접 개발할 수 있어 외부 하네스로 지속학습 문제가 해결될 가능성을 낮게 평가함
- 합성 데이터, 증강, 사람이 설계한 귀납 편향은 쓴 교훈(bitter lesson) 에 반하는 우회책으로 봄
  - 이런 기법 없이 벤치마크를 확장하기 어렵다는 사실은 추가 돌파구가 필요함을 보여줌
LLM의 ARC-AGI 성과에서 관찰한 점
- 초기 LLM은 사람에게 쉬운 ARC에서 성능이 낮았으며 사전학습만으로 일반 추론 능력이 자동으로 생기지 않았음
- OpenAI o1이 ARC-AGI-1에서 75% 를 기록한 것은 충분한 데이터가 있으면 사후학습으로 특정 과제를 학습할 수 있음을 보여준 사례로 봄
- ARC-AGI-2가 공개되자 추론형 모델을 포함한 LLM의 성과가 다시 낮아짐
  - ARC-AGI-1 성능이 ARC-AGI-2로 자동 이전되지 않아 사후학습 역시 일반 추론 능력을 보장하지 않음
  - 모델이 일반 추상 추론보다 ARC 퍼즐 풀이 방식을 학습하고 있을 수 있음
- 이후 추론형 LLM의 ARC-AGI-2 성능은 꾸준히 올랐지만 기본 모델은 한 자릿수에 머묾
  - ARC-AGI-2 점수는 주로 사후학습에 의해 상승한다고 봄
  - 합성 ARC 데이터의 양이 주요 요인일 가능성을 제시함
  - LLM은 표본 효율적이지 않다고 판단함
- 계산량과 데이터 증가에 따라 성능은 계속 개선될 것으로 보며, 추론 비용 감소도 긍정적으로 평가함
전체 구현 변경 사항
- 훈련 동역학을 바꾼 요소는 다음과 같음
  - AdamW 단독 구성에서 NorMuon과 보조 AdamW 조합으로 변경함
  - 워밍업·코사인 학습률에서 워밍업·유지·선형 감쇠로 이어지는 WSD 스케줄로 전환함
  - LayerNorm 을RMSNorm 으로 교체함
  - Linear → GELU → Linear FFN을chunk + SiLU gate 기반 SwiGLU로 교체함
  - Attention 가중치, 토큰 임베딩, 과제·이면체 임베딩에 별도의 가중치 감쇠 값을 적용함
  - outputs["loss"] 대신 출력 토큰만 포함하는outputs["output_loss"] 를 사용함
  - 길이 기반 스마트 버킷 대신 무작위 훈련 배치를 사용함
  - 불완전한 마지막 배치는 drop_last=True 로 제거함
  - ARC-AGI-1·2, ConceptARC, 필터링된 교차 데이터 세트, 제출·비공개 모드를 지원하도록 데이터 구성을 확장함
  - 전역 색상 순열 대신 예제별 색상·이면체 증강 튜플을 사용함
  - 출력에만 존재하는 색상은 색상 순열 대상에서 제외함
  - 과제 전체에서 변환된 입력을 해시로 중복 제거해 고유 표본 다양성을 높임
  - 증강 후보를 셔플하고 주기별 비복원 방식으로 선택함
  - 옵티마이저, 학습률, 에폭, 증강 한도·종류, n_layers , 데이터 경로를 조정함
  - 토큰 조건에 더하는 dihedral_embedding 을 추가했으나 성능 향상은 작았음
- 훈련 동역학을 유지하면서 속도를 높인 요소는 다음과 같음
  - 패딩된 [B,S] 배치 대신cu_seqlens 를 사용하는 압축 토큰 스트림으로 변경함
  - 패딩 SDPA 마스킹 대신 가변 길이 FlashAttention과 FlexAttention 디코드 커널을 사용함
  - 이면체 증강을 오프라인 데이터 확장에서 배치 구성 시점의 온라인 선택으로 옮김
  - 빌드 시 훈련 분할을 ("train","test") 에서("train",) 으로 변경함
