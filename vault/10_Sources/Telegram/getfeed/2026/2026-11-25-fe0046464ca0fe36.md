- Phoronix가 EPYC 9996과 EPYC 9686F를 1세대 EPYC 7601과 듀얼 소켓 구성으로 비교함. 100개 이상 벤치마크의 기하평균에서 각각 12.1배와 8.7배의 성능을 기록
- EPYC 7601에서 9996으로 넘어오며 소켓당 코어 수는 32개에서 256개, L3 캐시는 64MB에서 1,024MB로 증가함. 메모리와 명령어 처리 개선까지 포함한 서버 전체 성능 비교임
- OpenVINO 얼굴 인식 추론에서는 최대 133배의 처리량을 기록함. AVX-512 지원과 메모리 대역폭 증가 등이 더해져 작업에 따라 성능 향상 폭이 크게 달라짐
- 작업군별 기하평균은 AVX-512 활용 작업 16.4배, 콘텐츠 제작 13.6배, HPC 15.6배로, AI 외의 작업에서도 큰 성능 향상을 보임
- CPU당 기본 전력 정격은 180W에서 600W로 높아졌지만, 와트당 성능도 약 5배 개선됨. 모든 서버는 Ubuntu 26.10과 Linux 7.3, GCC 15.3 환경에서 비교함
EPYC Naples에서 Venice까지의 변화
- 새 EPYC 9006 “Venice” SP7 서버 프로세서가 출시됐으며, EPYC 9686F와 EPYC 9996은 Zen 5 Turin 대비 큰 세대 간 성능 향상을 보임
- EPYC 7601은 2017년 6월 출시된 1세대 EPYC “Naples” Zen 1의 최상위 모델임
  - 32코어/64스레드, 기본 2.2GHz, 최대 부스트 3.2GHz, L3 캐시 64MB
  - 8채널 DDR4-2666과 최대 128개의 PCIe 3.0 레인을 지원하며, CPU당 TDP는 180W
- EPYC 9996은 소켓당 Zen 6C 256코어/512스레드를 갖춘 최상위 모델임
  - 기본 2.55GHz, 최대 부스트 4.1GHz, L3 캐시 1,024MB, 기본 전력 정격 600W
  - EPYC 9006 SP7 플랫폼은 16채널 DDR5 RDIMM 또는 최대 MRDIMM-12800과 PCIe 6.0 레인 96개를 지원
- 고클럭에 최적화된 EPYC 9686F는 96코어/192스레드, 기본 4.05GHz, 최대 부스트 5.3GHz로 동작
  - L3 캐시는 384MB이며 기본 전력 정격은 600W
- 세대별 변화에는 사양표에 드러나지 않는 아키텍처 개선도 포함됨
  - Zen 4에서 AVX-512를 도입하고 Zen 5에서 추가로 개선
  - 보안 개선으로 소프트웨어 기반 보안 완화 조치의 필요성을 줄이는 등 Zen 1부터 Zen 6까지 여러 개선을 누적
비교 시스템과 측정 방식
- EPYC 7601 2P는 초기 Naples 테스트용으로 AMD가 제공했던 Dell PowerEdge R7425 서버를 사용했으며, 약 10년이 지난 뒤에도 안정적으로 동작
  - 메모리는 32GB DDR4-2666 16개, 저장장치는 Samsung SSD 860이며 나머지도 기존 리뷰 장비의 기본 구성
- EPYC 9686F 2P와 EPYC 9996 2P는 Nigeria 레퍼런스 서버에서 테스트
  - 메모리는 64GB MRDIMM-12800 32개, 저장장치는 Micron MTFDMBQ7T6THM-1BP1JABDC PCIe Gen6 SSD 사용
- 세 서버 모두 듀얼 소켓 구성이며, Ubuntu 26.10과 Linux 7.3, GCC 15.3으로 소프트웨어 환경을 통일
- 실제 워크로드의 처리 성능뿐 아니라 CPU 소비전력과 와트당 성능도 비교
  - 듀얼 소켓 구성에서 노출되는 CPU PowerCap/RAPL 센서로 전력을 측정
- 코어 수와 클럭, 캐시, 메모리, 명령어 지원이 함께 바뀐 비교이므로 전체 성능 배수를 코어당 성능이나 IPC 향상으로 해석할 수는 없음
100개 이상 벤치마크의 종합 결과
- 전체 벤치마크의 기하평균에서 EPYC 7601 2P 대비 EPYC 9996 2P는 12.1배, EPYC 9686F 2P는 8.7배의 성능을 기록
- EPYC 9996과 EPYC 7601의 작업군별 기하평균은 다음과 같음
  - AVX-512 활용 작업: 16.4배
  - 콘텐츠 제작 작업: 13.6배 — Blender 등을 포함
  - HPC 작업: 15.6배
- OpenSSL과 데이터베이스 같은 전통적인 Linux 서버 작업에서도 최대 22배의 성능 차이가 나타남
- 전체 결과와 개별 측정값은 Phoronix의 종합 결과에서 확인 가능
AI 추론에서 최대 133배의 처리량
- OpenVINO 얼굴 인식 추론에서 Zen 1 대비 Zen 6 계열의 처리량이 최대 133배로 증가
- 사람 검출 모델에서는 63배, 용접 기공 검출 모델에서는 125배의 처리량을 기록
- 용접 기공 검출 모델은 처리량뿐 아니라 지연시간과 전력 효율도 크게 개선
  - 지연시간은 약 39분의 1로 감소
  - 와트당 성능은 14배로 증가
- 코어 수와 클럭 증가 외에도 AVX-512, 더 빠른 메모리와 두 배로 늘어난 메모리 채널 등이 성능 차이에 기여
- 133배는 특정 얼굴 인식 추론 시험의 최대치이며, AI 작업 전체의 평균은 아님. OpenVINO 평가 결과
소비전력 증가와 전력 효율 개선
- EPYC 7601의 CPU당 TDP는 180W이며, EPYC 9996과 9686F의 기본 전력 정격은 600W
- 전력 정격은 3배 이상 높아졌지만, 실제 워크로드 성능과 CPU 소비전력을 함께 비교하면 와트당 성능은 약 5배 개선
- 이는 CPU 전력 센서로 측정한 효율이며, 메모리와 저장장치 등을 포함한 서버 전체 소비전력 기준과는 구분해야 함. 전력 효율 비교
