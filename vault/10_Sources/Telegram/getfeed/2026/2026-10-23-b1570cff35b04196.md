### datapitfalls - 차트뿐 아니라 데이터 분석 전 과정의 함정을 찾는 도구 | GeekNews

(https://news.hada.io/topic?id=35842)

- 데이터 분석 및 보고서 작성자를 위해 질문 설정부터 수집, 변환, 분석, 해석과 전달까지 오류와 편향을 점검하는 도구
- 축을 잘라낸 차트뿐 아니라 누락값 제거, 잘못된 JOIN, 생존자 편향, 상관관계와 인과관계 혼동, 유리한 기간만 고르는 문제 등을 검사
- 차트 이미지, Python/SQL/R 코드, 자연어로 설명한 분석 과정과 보고서를 입력해 문제점과 심각도, 근거, 수정 방법 확인
- 여러 차트를 함께 비교해 서로 다른 척도와 모순된 메시지를 찾고, 데이터 가공 코드부터 차트와 결론까지 여러 단계를 연결해 검토 가능
- 데이터 작업의 함정을 8개 영역으로 분류
  - 인식 오류, 기술적 오류, 수학적 오류, 통계적 오류
  - 분석 왜곡, 시각화 오류, 디자인 문제, 편향된 기준
- Ben Jones의 책 《Avoiding Data Pitfalls》를 바탕으로 8개 영역의 검사 규칙 제공
- 웹 앱에서 설치 없이 검사 가능
  - PDF의 본문과 차트/표, Word 문서, PowerPoint, Jupyter Notebook 등 지원
- Claude Code, Claude Desktop, claude.ai에 MCP로 연결해 분석과 차트 작성 과정에서 검사 기준 활용
  - MCP는 Claude에 규칙과 체크리스트를 제공하는 방식으로, 서버 자체에는 별도 Anthropic API 키 불필요
- 입력에서 확인된 문제와 추가 데이터 확인이 필요한 잠재적 문제를 구분해 결과 제공
- CLI의 --ci 모드는 입력에서 확인된 경고나 오류가 있으면 실패 종료 코드를 반환해 CI에 연결 가능
- 웹 스캐너의 입력은 Claude API로 전송되며, 웹 앱 자체에는 저장하지 않음
- 코드는 MIT, 검사 규칙은 CC BY-NC 4.0
  - 업무에서 자신의 자료를 검사하는 용도는 무료이며, 규칙을 유료 제품이나 서비스에 포함하려면 별도 라이선스 필요

## 텔레그램 수집 시 유의사항

- 이 컬렉터는 공개 웹 미리보기(t.me/s/{channel})만 수집하며, 비공개 채널 수집은 이 단계에서 구현하지 않는다.
- 웹 미리보기는 페이지당 최대 20개 메시지씩, 최대 10페이지(최근 약 200개)까지만 페이지네이션한다.
- 이미지, 동영상 등 미디어 전용 메시지(텍스트 없음)는 캡처하지 않는다.
