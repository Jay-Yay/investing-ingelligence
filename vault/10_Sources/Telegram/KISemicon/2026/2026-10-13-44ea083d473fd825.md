### [News] Samsung Showcases CXL Memory Expansion With AMD at OCP 2026, Expands AI Memory Push Beyond HBM

[News] Samsung Showcases CXL Memory Expansion With AMD at OCP 2026, Expands AI Memory Push Beyond HBM
As AI workloads drive growing demand for both memory bandwidth and capacity, memory makers are expanding their portfolios to include a wider range of AI memory solutions. According to ZDNet, Samsung Electronics teamed up with AMD to demonstrate a Compute Express Link (CXL)-based memory expansion solution at the OCP Global Summit 2026. Featuring Samsung’s CMM-D-based memory pooling technology, the solution enables multiple systems to share memory resources more efficiently and flexibly expand capacity.
As noted by NewsPim, Samsung sees CXL-based memory expansion as a way to overcome the capacity limitations of conventional systems, particularly as AI agents drive higher memory requirements for inference.
The demonstration follows a memorandum of understanding signed by Samsung and AMD in March to expand cooperation on next-generation AI memory and computing technologies. During her October 7 visit to South Korea, AMD CEO Lisa Su also discussed potential collaboration with Samsung in memory and foundry technologies, The Korea Times notes.
Samsung Expands AI Memory Portfolio With HBM5, Custom HBM, and Next-Generation SSDs
At the event, Samsung outlined plans to expand its AI memory and storage portfolio to address growing demands for processing speed, memory capacity, and data management. According to ZDNet, Samsung Executive Vice President Shim Ho-joon of the company’s AE Team highlighted next-generation technologies including HBM5, custom HBM, zHBM, and processing-in-memory (PIM), aimed at improving data processing speeds and computational efficiency.
Alongside these high-performance memory technologies, Samsung is developing CMM-D and CXL-based solutions to expand AI system memory capacity, while advancing next-generation SSD technologies, including quad-level cell (QLC) NAND and flexible data placement (FDP), to improve storage performance, capacity, and data management efficiency, the ZDNet report adds. Further addressing AI data management needs, Samsung showcased KV cache optimization and Direct Storage technologies at OCP, aimed at improving data processing efficiency across AI systems as inference workloads grow, NewsPim adds.
Samsung is also strengthening customer collaboration through its Samsung MAX Lab (Memory Application eXperience Lab). According to NewsPim, the initiative allows customers to evaluate emerging technologies, including PIM, CMM-D, and next-generation SSDs, under real-world AI workloads before commercialization, while incorporating their system requirements early in product development.
Samsung Highlights 4nm Groq Chips and 2nm GAA Technology
Separately, Samsung displayed a Groq LPU wafer and NVIDIA’s Groq 3 LPX system, with the chips mass-produced using Samsung Foundry’s 4nm process, according to ZDNet. The company also showcased a wafer manufactured using its 2nm gate-all-around (GAA), highlighting its foundry capabilities alongside its expanding AI memory and storage portfolio.

### [OCP in Focus] SK hynix Drives up to 5x Faster Time-to-First-Token with MARS; HBF Expands Capacity by 14x

(https://vo.la/AB8ou3G)

[OCP in Focus] SK hynix Drives up to 5x Faster Time-to-First-Token with MARS; HBF Expands Capacity by 14x
To break free from the ongoing memory crunch, SK hynix is pushing the boundaries of AI infrastructure beyond conventional HBM solutions. At the OCP Global Summit 2026, SK hynix Senior Vice President Hoshik Kim introduced MARS (Memory-Centric AI Rack-Scale System), a disaggregated rack-scale architecture designed to seamlessly coordinate compute and memory resources.
Notably, Kim also spotlighted the progress of HBF (High Bandwidth Flash), targeting the industry’s pressing capacity constraints. Here is TrendForce’s on-site summary of his key remarks.
MARS: Boosting TTFT up to 5x to Solve Processor-Centric Cluster Bottlenecks
According to Kim, traditional processor-centric architectures face severe structural limitations in distributed computing clusters. These include resource imbalance—where idle memory on one server cannot be easily shared with another—as well as rigid scalability, where adding memory requires purchasing an entire new server node. Consequently, operators are forced into GPU over-provisioning, driving up TCO and creating system inefficiencies.
“By memory disaggregation, this decouples memory from traditional CPU/GPU server constraints, creating a dedicated, massive memory pool… we can actually move from a per-server memory headroom to a pool-level efficiency,” Kim said.
As explained by Kim, MARS is a disaggregated rack-scale memory system that coordinates compute and memory as a shared infrastructure. “Now we are expanding this concept of the memory tray-level memory pool as a rack-scale memory pool.”
Highlighting the real-world performance gains enabled by MARS, Kim noted: “We applied this one into a multi-turn AI agentic AI inferencing service. And then by providing this system, we can actually consume and store this exploding KV cache through this multi-turn AI agents into a shared memory system without exhausting GPU memory and storage systems.”
“So if you look at this graph, we have a very good 3 to 5 times improvement in TTFT (Time To First Token) over recomputation, which is quite impressive, especially when you talk about this tail latency, tail latency is dramatically reduced.”
HBF: Delivering 14x HBM Capacity with Sampling Set for 2028
SK hynix also elaborated on its progress with High Bandwidth Flash (HBF), highlighting its key performance strengths.
“Basically, HBM is a good memory… So HBF expands this HBM-class bandwidth to rack-scale capability/capacity… HBF is typically half the bandwidth of HBM, but more like 14 times higher capacity than HBM,” Kim said.
He confirmed that product development is well on track. “Recently in July, we released OCP HBF spec version 0.7… expecting to release spec version 1.0 early next year, and currently developing HBF concept prototype, and we’ll sample HBF Cube available early 2028.”
