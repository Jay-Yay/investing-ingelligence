- CPU, 패키징, 기판, 전력, 인터커넥트, 아날로그까지 돈이 돎
- 그래서 다음 병목이 어디냐가 핵심

2. 인텔·퀄컴이 오른 이유
- 에이전트 AI는 단순히 답만 뽑는 구조가 아님
- 툴 호출, DB 검색, 작업 분배, 기록 관리까지 해야
- 이때 전체 작업을 조율하는 CPU 역할이 커짐
- 그래서 인텔, AMD, ARM 같은 서버 CPU가 살아남
- 퀄컴은 데이터센터보단 온디바이스 AI, 엣지 AI, 무선/RF 쪽 수혜 기대

3. 그래도 본진은 메모리
- CPU 수요가 늘어도 메모리가 필요
- GPU가 늘어도 HBM이 필요
- 에이전트가 길게 생각하고 기록을 유지해도 DRAM, SSD, 캐시 수요 상승
- 그래서 CPU 내러티브는 맞지만, 넓게 보면 메모리가 훨씬 강력한 병목
- CPU는 새로운 수혜, 메모리는 모든 시나리오의 공통 수혜

4. 반도체 랠리 구조
- AI는 연산만의 문제가 아님
- 연산이 커지면 메모리가 막힘
- 메모리가 커지면 패키징이 막힘
- 서버가 커지면 전력과 냉각이 막힘
- 데이터센터가 커지면 네트워크와 광통신이 막힘
- 즉, 하나의 테마가 아니라 병목이 순서대로 재평가되는 과정
