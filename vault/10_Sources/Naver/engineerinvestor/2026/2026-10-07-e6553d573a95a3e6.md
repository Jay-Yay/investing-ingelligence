## 원문

engineerinvestor — AI 에이전트가 CPU를 부르는 이유 (feat. GPU 하나에 CPU 하나) (2026-10-07T18:00:00+09:00)

요약:

AI 에이전트는 생각(GPU)과 실행(CPU)을 수십 번 번갈아 한다. 코딩 일 한 건에 CPU가 일하는 시간은 GPU의 약 50배다.

인텔 CEO는 2026년 4월 실적발표에서 "CPU 대 GPU 비율이 1:8에서 1:4가 됐고, 1:1이나 그 이상으로 갈 수 있다"고 말했다. AMD CEO 리사 수도 2026년 5월 "1:1에 가까워지고 있다"고 했다.

비율이 1:4에서 1:1로 가면, GPU 수가 그대로여도 필요한 CPU는 4배가 된다.

다만 인텔 데이터센터 부문 매출 +59%(2026년 2분기)는 대부분 서버 판매가 상승(+48%)에서 나왔고, 서버 출하량은 +9%였다. 에이전트 수요가 개수로 찍히는지가 다음 분기점이다.

0. AI 주식 하면 GPU부터 떠올리는 당신에게

​

AI 반도체 얘기가 나오면 다들 GPU부터 떠올린다. 엔비디아, HBM, 데이터센터 전력. 이 셋이면 대화가 끝난다.

그런데 요즘 CPU 회사 사장들이 이상한 말을 하기 시작했다. "앞으로는 GPU 하나에 CPU 하나가 붙는다."

​

CPU라니. 노트북 광고에서나 보던 그 칩이다. AI 시대에 조연으로 밀려났다고들 했던 그 칩이다. 적어도 CPU 회사 실적발표가 이렇게 재밌었던 적은 오랜만이다.

​

이 글은 그 말이 어디서 나왔고, 맞다면 돈이 어디로 흘러가는지를 따라간다. 챗봇과 에이전트의 차이에서 시작해 CPU 칩, 그 밑의 기판, 그 옆의 메모리 모듈까지 내려간다.

(뒷북일 수 있지만 그래도 공부하고 넘어가자)

1. 챗봇과 에이전트, CPU가 하는 일이 다른 이유

​

AI 서비스 안에는 두 종류의 칩이 일한다.

​

GPU는 AI 모델을 돌린다. "다음에 무엇을 할지" 생각하는 칩이다. CPU는 컴퓨터의 일반 업무를 한다. 파일을 열고, 웹페이지를 띄우고, 프로그램을 실행한다.

​

챗봇은 질문을 받으면 GPU가 답을 만들고 끝난다. CPU가 할 일은 거의 없다.

​

에이전트는 다르다. 모델이 "이 웹페이지를 열어 봐"라고 정하면, CPU가 실제로 페이지를 연다. 그 결과를 모델이 읽고 다음 행동을 정한다. 일이 끝날 때까지 이걸 수십 번 반복한다.

​

사람으로 치면 GPU는 판단하는 머리고, CPU는 서류를 찾고 전화를 거는 손발이다. 챗봇은 머리만 쓰는 상담이고, 에이전트는 머리와 손발을 번갈아 쓰는 업무 대행이다.

​

얼마나 차이가 나는지 숫자로 보자. 코딩 에이전트에게 "결제 페이지 오류를 고쳐 달라"는 일 하나를 맡겼다고 하자. 에이전트는 코드를 검색하고, 파일을 읽고, 고친 뒤 테스트를 여러 번 돌린다. 모델 호출 12번, 프로그램 실행 16번이 따라온다.

​

이 일 한 건에 GPU가 일한 시간은 약 8초다. CPU 코어가 일한 시간은 415초다. 약 50배다. 노트북 CPU 코어 하나를 7분 가까이 쉬지 않고 돌린 양이다.

​

사람은 "고쳐 줘" 한마디 했을 뿐이다. 그 뒤에서 컴퓨터 한 대 분량의 일이 벌어진다.

2. 에이전트 한 건에 CPU는 얼마나 필요한가

​

한 건에 7분이면 별것 아닌 것 같다. 근데 여기에 두 가지가 곱해진다.

​

일하지 않는 동안에도 자리를 잡고 있다

​

에이전트는 사용자마다 따로 만든 작은 가상 컴퓨터 안에서 일한다. 남의 파일이 섞이면 안 되고, 에이전트가 실수로 위험한 프로그램을 돌려도 다른 사용자에게 번지면 안 되기 때문이다.

​

아마존이 만든 이런 가상 컴퓨터 기술(Firecracker)은 하나를 띄우는 데 0.125초가 안 걸린다. 그래서 작업마다 새로 띄우는 방식이 표준이 됐다.

​

문제는 이 작업 공간이 모델이 생각하는 동안에도 꺼지지 않는다는 점이다. 사람이 에이전트가 낸 중간 결과를 읽고 다음 지시를 고민하는 몇 분 동안에도 마찬가지다. 그동안 CPU는 아무 일도 안 하는데, 거기 배정된 CPU와 메모리는 다른 사람이 쓸 수 없다.

​

실제로 계산한 시간보다 자리를 잡고 있는 시간이 길다. 아래 계산에서는 이걸 2배로 잡았다.

​

​

이제 사용자 수와 하루 사용 횟수를 곱해 보자. 하루 종일 쉬지 않고 돌아야 하는 CPU 코어가 몇 개인지 나온다.

​

​

3. CPU:GPU 비율이 1:4에서 1:1로 바뀌는 이유

​

여기까지는 "CPU가 꽤 필요하다"는 얘기다. 이제 본론이다. 서버 구성 자체가 바뀌고 있다.

​

지금 AI 서버는 CPU 하나가 GPU 여럿을 거느린다

​

지금 AI 서버는 CPU 한 개가 GPU 여러 개를 거느리는 구조다. 학습용으로는 GPU 8개에 CPU 1개 꼴까지 갔다. 엔비디아의 대표 서버(DGX B200)는 CPU 2개에 GPU 8개, 1:4다.

​

CPU가 맡은 일이 GPU에 일감을 나눠 주는 관리자 역할뿐이었기 때문이다. 관리자 한 명이 직원 여럿을 챙기면 됐다.

​

에이전트가 이 구도를 바꾼다. 일감을 나눠 주는 것 말고도 CPU가 직접 할 일이 생겼다. 1장에서 본 "실행"이다.

​

CPU 회사 사장들이 실적발표에서 한 말

​

2026년 4월 23일 인텔 실적발표에서 립부 탄 CEO는 이렇게 말했다. "CPU 대 GPU 비율이 1:8이었다가 지금은 1:4이고, 1:1이나 그 이상으로 갈 수 있다." 이유로는 작업 조율과 "여러 에이전트를 관리하는 일"을 들었다.

출처: 인텔 2026년 1분기 실적발표 녹취(2026-04-23, Motley Fool 전문)

​

같은 날 데이비드 진스너 CFO는 더 잘게 나눴다. 학습은 GPU 7～8개에 CPU 1개, 추론은 3～4개에 1개. 에이전트와 멀티 에이전트로 가면 "비율이 반대로 조금 뒤집힐 수도 있다"고 했다. CPU가 GPU보다 많아질 수 있다는 뜻이다.

​

열흘 남짓 뒤, 경쟁사 AMD의 리사 수 CEO도 같은 얘기를 했다. 2026년 5월 5일 실적발표에서다.

​

출처: AMD 2026년 1분기 실적발표 녹취(2026-05-05, Motley Fool 전문)

​

서로 점유율을 뺏는 두 회사가 같은 숫자를 말했다. 학습 1:8, 추론 1:4, 에이전트 1:1.

​

1:1은 어디서 나오나 — GPU 서버가 아니라 그 옆이다

​

여기서 짚어야 할 게 있다. 엔비디아의 최신 GPU 랙은 지금도 CPU 36개에 GPU 72개다. 1:2다. 다음 세대인 Vera Rubin 랙도 36:72로 같다.

​

출처: 엔비디아 GB200 NVL72 제품 페이지

​

그러면 1:1은 어디서 나오나. GPU 랙 옆에 따로 세우는 CPU 전용 서버에서 나온다.

​

엔비디아가 바로 그 물건을 내놨다. 2026년 3월 16일 엔비디아는 GPU 없이 Vera CPU만 256개 넣은 서버 랙을 발표했다. 이 랙 하나로 독립된 CPU 작업 환경을 2만 2,500개 넘게 동시에 돌린다. 2장에서 본 "사용자마다 따로 띄우는 작업 공간"이 바로 이것이다.

​

출처: 엔비디아 보도자료(2026-03-16)

​

GPU를 파는 회사가 CPU만 든 랙을 따로 만들었다. 엔비디아도 손발 쪽 시장이 따로 커진다고 본 것이다.

​

정리하면 1:1은 서버 한 대 안의 비율이 아니다. GPU 랙과 CPU 전용 랙을 합친 데이터센터 전체를 놓고 센 비율이다. 그래서 이 얘기가 맞는지는 CPU 전용 서버가 실제로 몇 대 깔리는지로 확인된다.

NVIDIA Vera CPU rack 256 (출처: NVIDIA)

숫자로 바꾸면 4배

​

GPU를 100만 개 들인 데이터센터를 생각해 보자.

​

지금의 1:4에서 1:1로 가면, GPU가 한 개도 더 늘지 않아도 CPU는 4배가 필요하다. GPU 수요까지 같이 늘면 이 효과는 곱해진다.

​

이게 이 글의 투자 아이디어다. 한 줄로 쓰면 이렇다.

​

에이전트가 일을 한다 → GPU 1개에 붙는 CPU가 ¼개에서 1개로 늘어난다 → CPU마다 붙는 기판·메모리 모듈 수요가 GPU보다 빨리 는다.

​

CPU가 "GPU를 따라 조금 더 팔리는 부품"에서 "GPU보다 빨리 느는 부품"으로 바뀌는 지점이다.

4. 그래서 돈은 어디로 흘러가나 — 서버 CPU에서 기판, 메모리 모듈까지

​

CPU 칩은 혼자 서버에 꽂히지 못한다. CPU가 한 개 늘면 반드시 따라 늘어나는 부품이 있다. 한 고리씩 내려가 보자.

​

고리 1. 서버 CPU

​

서버용 CPU를 만드는 곳은 크게 둘이다. 인텔·AMD의 x86 칩, 그리고 Arm 설계를 쓰는 칩(아마존 Graviton, 엔비디아 Vera 등)이다.

​

인텔 데이터센터 부문의 2026년 2분기 매출은 63억 달러(약 8.5조 원)다. 전년 대비 59% 늘었다. 인텔은 2분기 분기보고서에서 "수요가 공급을 넘었고, 업계 공급 부족이 내년까지 갈 것"이라고 적었다.

​

근데 이 숫자를 뜯어보면 눈여겨볼 게 있다.

​

인텔 2026년 2분기 분기보고서(10-Q, 2026-07-24 제출) (출처: Intel)

​

서버 매출 증가는 대부분 평균 판매가 상승(+48%)에서 나왔다. 출하량은 9% 늘었다. 인텔은 판매가 상승의 대부분이 고가 제품 비중이 늘어난 결과이고, 가격 인상은 일부라고 밝혔다.

​

고객이 더 비싼 칩을 산 건 맞다. 하지만 개수로는 아직 9%다. 3장의 "4배"는 아직 숫자로 찍히지 않았다. 이 숫자가 두 자릿수 중반을 넘어가는지가 이 글이 맞았는지를 가르는 첫 신호다.

​

고리 2. CPU를 얹는 패키지 기판

​

CPU 칩 아래에는 수천 개의 미세한 연결선을 서버 보드에 맞게 넓혀 주는 받침판이 있다. 이걸 FC-BGA 기판(반도체 패키지 기판)이라고 부른다. CPU 하나에 기판 하나다. 고성능 칩일수록 기판이 크고 층이 많아 만들기 어렵다.

​

삼성전기는 반기보고서에 "서버 CPU 패키지기판 플랫폼 양산 확대"를 적었다. 그리고 2026년 9월 28일 패키지기판 증설에 세종 4조 2,700억 원, 베트남 2조 5,100억 원을 쓰겠다고 공시했다. 합치면 약 6조 8천억 원이다. 세종 증설만으로 자기자본의 43.6%다. 완공 목표는 2028년 상반기다.

​

공시에는 "패키지기판"이라고만 적혀 있고, 이 중 서버 CPU용이 얼마인지는 나와 있지 않다. 그래도 자기자본의 절반 가까이를 기판 공장에 쓰는 결정은, 이 회사가 2028년 이후에도 고성능 기판이 모자랄 거라고 본다는 뜻이다.

​

대덕전자는 대면적·26층 FC-BGA 개발을 마쳤다. LG이노텍은 서버·데이터센터용 FC-BGA 경쟁력 강화를 방향으로 제시했다. 두 회사 모두 공시상 서버 CPU용 양산이 확정된 단계는 아니다.

​

고리 3. CPU 옆 메모리 모듈 — SOCAMM

​

CPU는 일하는 동안 데이터를 메모리에 올려 둔다. 엔비디아 Vera는 스마트폰용 저전력 D램(LPDDR)을 작은 판에 모아 끼웠다 뺄 수 있게 만든 모듈을 쓴다. 이걸 SOCAMM이라고 부른다. 2026년 6월 업계 표준(JEDEC)이 됐다. Vera CPU 한 개에 최대 1.5TB가 붙는다.

​

이 모듈도 CPU 하나마다 따라 붙는다. CPU가 4배면 SOCAMM 자리도 그만큼 는다.

​

SK하이닉스는 2026년 4월 20일 192GB SOCAMM2 양산을 시작했다고 발표했다.

마이크론도 대량 생산에 들어갔고, 회계연도 4분기(2026년 6～8월) 관련 매출이 전분기 대비 2배 이상이라고 밝혔다. 삼성전자는 공시상 SOCAMM2 개발(2025년 12월) 단계로 적혀 있다.

​

고리 4. 모듈을 만들고 검사하는 부품

​

메모리 모듈이 늘면 완성품을 검사하는 소켓과 테스터가 따라 필요하다. ISC는 반기보고서에 2분기 SOCAMM2 테스트 솔루션 초도 공급을 시작했다고 적었다. 티엘비는 메모리 제조사들과 SOCAMM 개발에 참여하고 양산 대응 중이라고 밝혔다. 공급 확정은 아니다.

​

같은 동작이 CPU 말고도 수요를 만든다

​

CPU는 한 갈래일 뿐이다. 작업 공간을 띄우면 그 안에서 쓸 서버 D램도 같이 떼어 준다. 어제 하던 일을 오늘 이어 하려면 작업 공간을 통째로 저장해야 하니 데이터센터용 SSD가 는다. 지난 9월 27일 글(AI 모델 구조가 바뀌면 메모리 수요는 줄어드나)에서 "에이전트가 늘수록 서버 D램 수요가 는다"고 쓴 것도 같은 줄기다.

5. 이 얘기가 틀릴 수 있는 지점

​

좋은 얘기만 하면 반쪽이다. 이 사슬이 끊길 수 있는 자리가 네 군데 있다.

​

첫째, 1:1을 말하는 쪽은 CPU를 파는 회사다. 인텔과 AMD는 이 비율이 오를수록 이득을 보는 쪽이다. GPU를 파는 엔비디아는 비율 숫자를 내놓은 적이 없다. CPU 전용 랙을 만들었을 뿐이다.

​

둘째, 아직 개수가 아니라 가격이다. 4장에서 봤듯 인텔 서버 출하량은 9% 늘었다. 고가 제품 비중이 늘어난 건 좋은 신호지만, "CPU가 4배 필요하다"는 얘기와는 아직 거리가 있다.

​

셋째, 수혜자가 기존 강자가 아닐 수 있다. 아마존 Graviton, 엔비디아 Vera 모두 Arm 설계다. CPU 수요가 늘어도 그게 누구의 CPU인지는 다른 문제다. 다만 기판과 메모리 모듈은 x86이든 Arm이든 CPU 한 개마다 붙는다. 사슬 아래로 내려갈수록 이 질문에서 자유로워진다.

​

넷째, SOCAMM은 새 수요이자 대체재다. 기존 서버 메모리 모듈(RDIMM) 자리를 바꾸는 면이 있다. SOCAMM이 는다고 서버 메모리 총수요가 같은 만큼 느는 건 아니다.

​

주가가 빠진다면 투자자들이 붙잡을 근거는 이 문장일 것이다. "CPU 매출 증가는 고가 제품 효과였고, 에이전트 수요는 아직 개수로 안 보인다."

​

결론

​

에이전트는 AI가 생각만 하던 시절에서 일을 하는 시절로 넘어가는 장치이고, 그 일의 몫은 CPU에 떨어진다. CPU 회사들의 "1:1" 발언이 맞다면, CPU는 GPU 투자에 딸려 가는 부품이 아니라 GPU보다 빨리 느는 부품이 된다. 그 효과는 CPU 칩 회사보다 CPU 한 개마다 반드시 붙는 기판과 메모리 모듈 쪽에서 더 안정적으로 나타날 수 있다. 누구의 CPU가 이기든 기판과 모듈은 필요하기 때문이다. 다만 지금 보이는 건 판매가 상승이지 개수가 아니다. 인텔 서버 출하량이 두 자릿수 중반을 넘고 CPU 전용 서버의 배치 숫자가 나오는 시점이 이 얘기가 숫자로 바뀌는 분기점이다.
