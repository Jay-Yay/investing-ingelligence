deskhunter — 오픈웨이트와 AI 수요의 저변 확장 (2026-09-19T21:24:17+09:00)

※26년 9월 7일 발간된 유진투자증권 박재환 연구원의 '오픈웨이트와 AI수요의 저변 확장' 참조

​

오픈웨이트 모델 점유율은 26년 6월 말 30%에서 8월 말 62.5%로 증가. 이와 함께 토큰 지출 인덱스는 5월 고점 이후 8월 말 거의 반토막. 이에 오픈웨이트 모델 점유율 증가로 인한 토큰가격 하락이 프론티어 랩의 매출을 저해하는 것이 아니냐는 우려 발생. 하지만

같은 기간 앤트로픽과 오픈AI의 7월 ARR은 증가. 특히 오픈AI는 ARR 상승속도 급증.

프론티어랩의 오픈라우터 토큰 사용 절대량 증가

로 미루어보면, 저가형 모델로의 '증분 수요 분산'으로 보는 것이 합리적.

한편 오픈웨이트 모델 점유율 증가세를 고려하면 프론티어 ARR은 AI 전방수요를 대표하는 지표에서 AI 전방수요의 일부만을 포착하는 지표로 위상이 변화하고 있다고 판단.

이에 AI 전방수요는 인프라 단 지표로 측정하는 것이 적합하다고 판단. 예를 들면

토큰 사용량

CSP/네오클라우드의 백로그

GPU 렌탈가 추이

데이터센터 계약 용량

등.

오픈웨이트 모델의 비용 중 학습은 증류로 아끼더라도 추론은 프론티어 랩과 동일하게 발생. 즉 오픈웨이트 모델의 낮은 토큰 가격이 낮은 추론 인프라 부담을 의미하지는 않음.

오픈웨이트 모델은 AI의 저변을 확장.

낮은 토큰가격: 제본스의 역설. 7월 말/8월 오픈AI 주요모델 가격인하 이후, 오픈라우터 기준 8월 오픈웨이트/프론티어 모두 사용량 폭증. 즉 점유율 뺏기 경쟁이 아닌 총 사용량 증가.

모델 커스터마이징: 오픈웨이트 모델은 가중치 공개되어 있어, 커스터마이징을 통해 사내 워크로드 최적화 가능.

온프레미스: 델에 따르면 전 세계 데이터 83%는 온프레미스에 위치해 있으므로, 연산을 데이터가 있는 곳으로 가져가야. 이는 하이퍼스케일러를 경유하지 않는 별도의 수요 채널 형성의 의미.

델의 AI 팩토리 도입 기업, 25년 3월 2000개 → 26년 9월 6500개.

프론티어 랩은 토큰당 추론 원가 (추론 인프라 비용)을 낮춰야 오픈웨이트 모델의 추격을 따돌릴 수 있음. 이는 MW당 토큰효율이 높은 최신 AI가속기 수요를 자극.

오픈웨이트 모델은 기본적으로 파편화. 소수의 표준화된 모델을 대규모로 서빙하는 프론티어 모델 구조와 다름. 인프라 사업자는 다수의 커스텀 모델을 수용할 수 있는 유연성 요구됨.

프론티어 모델: 하이퍼스케일러 위주. 자사의 컴퓨팅에 자사의 모델이 얹혀질 때 부가가치 극대화.

오픈웨이트 모델: 엔비디아+네오클라우드 위주.

엔비디아는 오픈웨이트 진영을 설계 중.

자사 오픈웨이트 모델 니모트론 출시.

풀사이드 (소프트웨어 엔지니어링/코딩 전용 파운데이션 모델 개발. 파운데이션 가중치 오픈웨이트로 공개) AI모델 개발 플랫폼 라이선스에 60억$ 지불.

오픈웨이트 AI모델 플랫폼 허깅페이스 인수.

엔비디아가 오픈웨이트 생태계를 확장하는 이유는 생태계 확장의 최대 수혜자이기 때문.

파편화된 수요에 대응해야 하는 환경에서 범용성은 강한 경쟁 우위.

오픈웨이트 모델의 절대 다수가 CUDA 기반으로 학습.

자체 생태계가 빈약한 집단(소버린, 엔터프라이즈 온프레미스)은 즉시 가동 가능한 통합솔루션에 대한 니즈가 있음.

이는 엔비디아에게

하이퍼스케일러 ASIC 수요잠식 리스크 분산

ACIE 중심 신규수요 창출

프론티어 모델 차세대 추론 인프라 수요 자극

네오클라우드도 오픈웨이트 생태계의 수혜.

특정 모델에 대한 이해관계 없음 (ex: 구글과 gemini)

엔비디아 중심의 클러스터 보유. 범용성에 강점.

상대적으로 하이퍼스케일러보다 저렴한 온디맨드 렌탈가격.

서빙 플랫폼으로 부가가치 창출. 시간당 과금에서 사용량 기반 과금으로.

모델의 구분

폐쇄형 모델: 학습과정, 가중치 전부 미공개

오픈웨이트 모델: 학습과정 미공개. 가중치 공개.

오픈소스 모델: 학습과정도 공개. 허깅페이스 등의 플랫폼을 이용해 배포됨.

오픈웨이트 모델의 BM

자체 API 서비스: 자사 인프라에서 모델 호스팅. 토큰사용량 기반 과금.

온프레미스 구축 서비스: 고객사 인프라에 모델 배포

오픈웨이트 모델의 가중치 공개는 채택률을 끌어올려 표준 지위 확보에 도움.

오픈웨이트 모델이 엔터프라이즈 자체 인프라에서 구동되면 모델랩 매출에 잡히지 않음. 즉 창출 가치가 모델 계층에서 인프라 계층으로 이전됨.

MoE 기법

모델을 다수의 전문가 네트워크로 분할하고, 입력 토큰마다 라우터가 소수의 전문가 집단만을 활성화.

연산을 줄여주는 효과가 있으나, 전체 전문가가 있는 가중치는 네트워크에 상주해야 함. 즉 메모리 부담은 줄이지 못함.

사후학습의 3가지 방식

지식 증류: 성능이 우수한 교사 모델이 학생 모델을 가르침. 학습 비용은 아낄 수 있으나 추론 비용은 동일.

파인 튜닝: 사전 학습된 모델 파라미터를 추가 학습으로 조정. 엔터프라이즈의 커스터마이징 주된 경로.

강화 학습: 모델 출력에 대한 보상으로 교정.

개인적인 정리

Astra가 나오면서 프론티어 랩이 치고 나가는 분위기. 하지만 늘 그렇듯 조금 시간이 지나면 중국(오픈웨이트)에서 프론티어를 따라잡는 기사가 나올 것이다.

반도체 투자자로서 투자를 지속할 수 있는 핵심 논쟁은 '시장의 걱정처럼 오픈웨이트가 이끄는 낮은 토큰가격이 AI CAPEX 투자를 낮추는가'일 것.

이 레폿은 위 의견의 반론이다. 오픈웨이트가 이끄는 낮은 토큰가격은 부가가치를 AI 인프라 기업에게로 이전한다는 것. 이게 사실이라면 중국의 저가 토큰의 추격을 너무 걱정할 필요는 없는 셈이다.

개인적으로도 토큰가격 하락 때문에 AI CAPEX가 줄어드는게 맞나?하는 의문이 있었다. 왜냐하면

AI CAPEX의 최대 수혜주인 엔비디아가 오픈웨이트 진영을 지지한다는 것

토큰가격 하락 중에도 GPU 임대료가 상승하는 것

하이퍼스케일러들은 메모리와 LTA로 5년 이상의 장기계약을 묶었는데, 폐쇄형 vs. 오픈웨이트 중 어디가 이길지 모르는 상황에서 LTA가 진행된 것

등의 상황이 이해가 안 가서. 이 레폿은 이런 의문에 좋은 참고가 됐다.
