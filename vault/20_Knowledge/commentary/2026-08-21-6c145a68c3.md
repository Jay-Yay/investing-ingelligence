오픈AI, Codex 한도 축소 루머 해명

: 최근 일부 Codex 사용자 사이에서 사용량이 빠르게 소진되거나 계정별 한도가 다르다는 제보가 나오며, 공지 없이 사용 한도를 축소했다는 루머 확산

: 오픈AI 조사 결과 영향받은 사용자 상당수가 sub2api 이용. ChatGPT 구독을 API 트래픽으로 변환해 재서빙하거나 여러 사용자가 공유하는 방식으로, 부정사용 방지 시스템의 제한 대상

: 오픈AI는 일반 사용자의 Codex 한도를 비공개로 축소한 것은 아니라고 해명. 공식 클라이언트뿐 아니라 Pi, OpenCode 등 OSS 클라이언트도 ChatGPT 계정으로 직접 로그인해 본인 구독 사용량을 쓰는 것은 정상적으로 허용

: 다만 sub2api를 사용하지 않거나 계정이 flag되지 않은 사용자도 한도가 크게 감소했다는 반론도 존재
