Elgato Key Light Mini - 서명된 펌웨어도 메모리 쓰기로 우회
- Elgato Key Light Mini 분석에는 Claude 작업 2.4시간과 사용자 프롬프트 10개가 사용됨

 - 서명 검증에 실패한 펌웨어는 거부함
 - 같은 네트워크에 있는 클라이언트에는 인증 없이 접근을 허용하므로 USB 장치와 위협 모델이 다름
- 서명 검증은 업데이트할 때만 실행되며 부트로더가 부팅 시 확인하는 보안 부팅 체계는 아님
 - 업데이트 중에도 장치의 다른 기능이 계속 동작함
 - 서명 검증 자체를 무력화할 수 있는 공격 표면이 남아 있음
- HTTP POST 요청으로 데이터를 내부 UART에 직접 전달할 수 있음
 - UART 명령에는 메모리 읽기·쓰기가 포함됨
 - ATSE=0200ED94,0E001009 를 한 번 보내면 서명 검사 함수가 아무 작업도 하지 않게 됨

- 장치 이름을 변경하는 단순 패치로 우회가 실제 동작함을 검증함
- 같은 네트워크에 있는 누구나 인증 없이 접근할 수 있으므로 신뢰할 수 없는 네트워크에 연결하지 않아야 함

- 운영체제는 연결된 장치가 원래 역할을 계속 수행하는지 검증할 준비가 충분하지 않음

- WebUSB·WebHID·WebBluetooth를 사용하는 장치는 사용자가 권한 요청을 한 번 잘못 승인하는 것만으로 영구 백도어가 설치될 가능성이 있음
- 문서화한 5종 외에도 상용 Dell 디스플레이에서 root 셸을 얻고 Eaton UPS에서 원격 코드 실행에 성공함

 - 에이전트가 제공하는 속도와 규모 때문에 위험이 더 커짐
