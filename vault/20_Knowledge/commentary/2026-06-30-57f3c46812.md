: ‘Sonnet 모델 가운데’ 가장 높은 에이전트 성능 강화. 추론, 코딩, 도구 활용, 지식노동 전반에서 Sonnet 4.6 대비 성능 향상

: Opus 4.8에 근접한 성능을 더 낮은 가격으로 제공. 중간 연산(Effort) 수준에서 비용 대비 성능이 크게 개선. 일부 작업에서는 높은 연산 수준에서 Opus 4.8과 유사한 성능 달성

: 안전성 개선. 악의적 요청 거부, 프롬프트 인젝션 방어, 환각 및 아첨 발생률이 Sonnet 4.6보다 감소. 다만 Opus 4.8 및 Mythos Preview 대비 일부 비정렬 행동은 다소 높게 평가

: 사이버보안 특화 학습은 적용하지 않았으며, Opus 계열 대비 취약점 익스플로잇 개발 능력은 크게 낮은 수준. 기본적으로 실시간 사이버보안 보호장치를 활성화해 출시

: Free, Pro 기본 모델로 제공. Max, Team, Enterprise, Claude Code, API에서도 이용 가능

: 출시 기념 가격은 8월 31일까지 인풋$2 및 아웃풋 $10/백만토큰. 이후 인풋 $3및 아웃풋 $15로 인상

: Artificial Analysis Index 53점. GPT-5.5(High)와 동일하나 Opus 4.7 및 4.8 대비 낮은 수준

: 프로모션 가격 적용 x 시 작업 당 비용은 $2.29. Opus 4.8 대비 15% 높은 수준 

: Sonnet 4.6의 업그레이드 버전이지만, 성능 향상을 위해 신규 토크나이저 사용(Opus 4.7 도입 토크나이저 변경과 유사). 동일 입력이라도 더 많은 토큰으로 변환 가능성 언급
