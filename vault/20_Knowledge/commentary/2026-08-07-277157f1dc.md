## 첨부 기사 원문
### Qwen3.8 Max, Agentic Index 종합 1위 | GeekNews

(https://news.hada.io/topic?id=32216)

- Qwen3.8 Max가 도구 사용·계획·자율성·복합 문제 해결을 측정하는 Artificial Analysis Agentic Index에서 종합 최고 모델로 평가됨
- Agentic Index는 특정 역량과 산업별 성능을 측정하는 Capability Indices 중 하나로, 총 24개 모델을 비교함
- 별도 지표인 Intelligence Index v4.1.1은 GDPval-AA v2, τ3-Banking, Terminal-Bench v2.1 등 9개 평가를 결합하며 비용·소요 시간·출력 토큰도 함께 비교함
- 모델 외에도 코딩 에이전트, 이미지·영상·음성, 개방성, API 속도·지연 시간과 제공자별 엔드포인트 정확도를 독립적으로 평가함
- 모델을 선택할 때는 지능 점수뿐 아니라 작업당 비용, 실행 시간, 출력 속도, 가중치 공개 여부와 실제 엔드포인트의 정확도 보존 수준까지 함께 확인할 수 있음
Qwen3.8 Max와 Agentic Index
- Qwen3.8 Max는 8월 5일 새 언어 모델 평가 대상으로 추가됐으며, Hacker News 제목 기준 Agentic Index 종합 1위에 오름
- Artificial Analysis Agentic Index는 에이전트 워크플로에서 나타나는 도구 사용, 계획, 자율성, 복합 문제 해결 성능을 측정함
- 총 24개 모델이 포함되며, 추론 모델은 전구 아이콘으로 구분됨
- 금융·회계, 전략·운영, 법률, 의료, 엔지니어링, 경제학과 함께 특정 역량과 산업을 평가하는 Capability Indices에 속함
Intelligence Index v4.1.1
- Artificial Analysis Intelligence Index v4.1.1은 독립적으로 실행한 9개 평가를 결합함
 - GDPval-AA v2: 현실에서 경제적 가치가 있는 직무 과제
 - τ3-Banking: 에이전트형 도구 사용
 - Terminal-Bench v2.1: 에이전트형 코딩과 터미널 사용
 - SciCode: 코딩
 - Humanity's Last Exam: 추론과 지식
 - GPQA Diamond: 과학적 추론
 - CritPt: 물리학 추론
 - AA-Omniscience: 지식과 환각
 - AA-LCR: 긴 문맥 추론
- 대시보드는 전체 595개 모델 가운데 선택된 26개 모델을 지능, 비용, 시간, 출력 토큰 기준으로 비교함
- 모델은 공개 가중치, 상업적 사용이 제한된 공개 가중치, 독점 모델로 구분되며 입력 유형과 국가별 필터도 제공함
- 가중치가 공개됐더라도 상업적 이용에 유료 라이선스 등이 필요하면 Commercial Use Restricted로 표시됨
- Intelligence Index 방법론에서 각 평가의 구성과 실행 방식을 확인할 수 있음
지능 대비 비용과 실행량
- 작업당 비용은 각 평가의 입력, 캐시 적중, 캐시 쓰기, 추론, 답변 토큰 가격을 작업 수로 나눈 뒤 Intelligence Index 가중치를 적용한 값임
- 비용 차트는 작업당 가중 평균 비용을 USD로 표시하며 낮을수록 좋음
- 지능과 작업당 비용의 관계에는 가장 매력적인 사분면과 Pareto 선이 표시됨
- 전체 Intelligence Index 실행 비용은 반복 실행을 제외하고, 평가 전반에서 사용된 토큰 수와 입력·캐시·추론·답변 가격으로 계산함
- 캐시 적중 가격은 이미 처리된 프롬프트의 토큰당 가격으로, 일반 입력보다 보통 크게 할인됨
 - 캐시 쓰기와 저장 비용은 별도로 청구되며 제공자마다 다름
- 작업당 출력 토큰은 각 평가의 출력 토큰 수에 상대 가중치를 곱한 뒤, 반복 실행을 제외한 작업 수로 나눠 계산함
- 작업당 시간은 출력 토큰 수를 출력 속도로 나눈 뒤 각 벤치마크의 상대 가중치를 적용함
 - TTFT와 기타 오버헤드는 제외됨
용도별 세부 지능 평가
- 독립 평가 목록에는 Intelligence Index 구성 요소 외에도 여러 에이전트·업무 평가가 포함됨
 - AA-Briefcase: 장기 지식 업무
 - AutomationBench-AA: 에이전트형 SaaS 워크플로
 - Harvey LAB-AA: 법률 에이전트 업무
 - EnterpriseOps-Gym-AA: 기업 운영
 - IFBench: 지시 준수
 - APEX-Agents-AA: 장기 에이전트 과제
 - ITBench-AA: Kubernetes 장애의 근본 원인 분석
 - MMMU-Pro: 시각적 추론
- 일반 지능은 여러 사용 사례로 이어질 수 있지만, 실제 용도에 따라 특정 평가의 관련성이 더 높을 수 있음
장기 지식 업무와 사실 신뢰성
- AA-Briefcase는 스프레드시트, 프레젠테이션, 메모 같은 결과물을 요구하는 현실적인 비즈니스 워크플로에서 장기 지식 업무를 시험함
- AA-Briefcase Elo는 루브릭 통과율, 분석 품질 Elo, 프레젠테이션 Elo를 결합함
 - 루브릭 성능은 합성 일대일 대결을 통해 Elo로 변환됨
 - Elo와 95% 신뢰구간 경계는 0 미만으로 내려가지 않도록 제한됨
- AA-Omniscience Index는 정확한 답에 보상하고 환각에 불이익을 주지만, 답변 거부에는 불이익을 주지 않음
 - 점수 범위는 -100부터 100까지임
 - 0은 정답과 오답 수가 같음을 뜻하며, 음수는 오답이 정답보다 많음을 나타냄
- GDPval-AA v2는 다양한 직업의 현실적이고 경제적 가치가 있는 과제를 평가함
 - 인간 기준점은 Elo 1,000으로 고정됨
코딩·이미지·영상·음성 평가
- Coding Agent Index는 종단 간 소프트웨어 엔지니어링 과제에서 성능, 비용, 실행 시간을 비교함
 - DeepSWE, Terminal-Bench v2, SWE-Atlas-QnA의 pass@1 복합 평균을 사용함
 - 총 52개 모델 중 선택된 15개를 모델 또는 에이전트 기준으로 표시함
- 이미지·영상 리더보드는 Image Arena와 Video Arena 결과를 95% 신뢰구간과 함께 제공함
 - 텍스트→이미지, 이미지 편집, 텍스트→영상, 이미지→영상, 영상 편집을 구분함
 - 텍스트→이미지는 블라인드 선호 투표에서 얻은 Elo 점수를 사용함
- 음성 평가는 텍스트→음성, 음성→텍스트, 음성→음성을 포함함
 - Speech Arena의 사용자 응답으로 상대적 품질 Elo를 산출함
 - 충분한 표를 얻지 못한 모델은 표시되지 않을 수 있음
모델 개방성
- Artificial Analysis Openness Index는 모델 구성 요소의 가용성과 투명성을 기준으로 개방성을 평가함
- 사전 학습 데이터 투명성, 사후 학습 데이터 투명성, 방법론 투명성, 모델 가용성을 구성 요소로 삼음
- 최대 점수는 18점이며 높을수록 더 개방적임
- 개방성 점수와 Intelligence Index의 관계도 함께 비교하며, 매력적인 사분면과 Pareto 선을 표시함
API 속도와 지연 시간
- 출력 속도는 스트리밍을 지원하는 모델에서 첫 API 청크를 받은 뒤 생성되는 초당 출력 토큰 수로 측정함
- OpenAI의 o1처럼 자체 API가 있으면 첫 번째 당사자 API 성능을 사용함
- Meta의 Llama처럼 자체 API가 없으면 여러 제공자의 중앙값을 적용함
- 작업당 디코딩 시간은 출력 토큰 수와 출력 속도로 계산하며 낮을수록 좋음
- 대시보드는 지능 대비 속도, 시간 대비 비용, 종단 간 응답 시간도 비교함
제공자별 엔드포인트 품질
- Endpoint Accuracy Index는 같은 모델을 제공하는 각 API 엔드포인트가 기준 엔드포인트의 정확도를 얼마나 보존하는지 측정함
- gpt-oss-120b(high)는 BFCL v4-500, HLE-250, AA-LCR-25를 결합해 17개 제공자를 비교함
- 자체 호스팅 기준 엔드포인트가 있으면 100을 기준으로 백분율을 표시함
 - 100은 기준과 같은 정확도를 뜻함
 - 낮은 점수는 양자화, 기본 샘플링 설정 또는 기타 엔드포인트 구성으로 정확도가 손실됐음을 나타냄
- 점수는 특정 시점의 스냅샷이며 방법론에 측정 방식이 공개돼 있음
- 제공자 비교에는 출력 속도, 혼합 토큰 가격, 캐시·입력·출력 가격과 Pareto 선이 포함됨
- 소규모 신흥 제공자도 높은 출력 속도와 경쟁력 있는 가격을 제공함
