📈AI 사용량, MAU 말고 토큰으로 봐야 source

1. Google 토큰이 폭발 중
- 월간 처리 토큰: 10T → 480T → 3,200T
- 이제 AI 사용량은 몇 명이나 쓰냐보다 얼마나 많이 태우냐가 중요
- 유저 수보다 유저당 작업량이 핵심

2. Gemini API도 같은 그림
- API token per minute: 0.06B → 2.8B → 19B
- AI가 챗봇 화면 안에만 있는 게 아니라, 앱·서비스·시스템 안으로 들어가는 중
- API 수요 증가는 곧 백엔드에서 AI가 계속 돌아간다는 뜻

3. 에이전트 시대가 왔다
- Claude Code는 1년 안에 70배 성장
- Codex extension은 6개월 만에 7배 성장
- 코딩 에이전트는 질문 한 번 받고 끝나는 구조가 아님
- 파일 읽고, 코드 짜고, 테스트하고, 다시 고치면서 토큰을 계속 태움

4. 결국 투자 포인트는 인프라
- 토큰 증가 → 추론 컴퓨트 증가
- 추론 컴퓨트 증가 → HBM·DRAM·SSD·전력 수요 증가
- AI 앱 성장의 후방에는 결국 메모리, 컴퓨트, 데이터센터가 있음

✍️AI 시대의 핵심 지표는 MAU가 아니라 token processed. 토큰이 많이 타는 만큼, 메모리와 전력도 함께
