Vercel AI Gateway, 오픈웨이트 모델 토큰 점유율 62%로 급증

: Vercel AI Gateway에서 오픈웨이트 모델 토큰 사용 비중이 8월 22일 역대 최고인 62% 기록. 폐쇄형 모델은 38%

: 불과 약 2개월 전인 6월 24일에는 오픈웨이트 28.4%, 폐쇄형 71.6%로, 오픈웨이트 비중이 두 배 이상 확대

: Vercel CEO Guillermo Rauch는 기업 AI 도입이 아직 초기 단계인 만큼 오픈웨이트 점유율 상승은 이제 시작일 가능성이 높다고 평가

: 향후 Harness, CLI, IDE, SDK 등이 특정 모델에 종속되지 않는 모델 애그노스틱 구조로 전환되면 가격, 성능 등에 따라 모델을 자유롭게 선택하는 환경이 확산될 전망

: 모델 간 성능 격차 축소와 라우터, 게이트웨이 확산이 오픈웨이트 모델 채택을 가속하는 흐름을 보여주는 사례. 다만 Vercel AI Gateway 사용량 기준으로 전체 AI 시장의 모델 점유율을 의미하는 것은 아님
