오픈AI, 추론 비용 절반 이하로 낮추는 최적화 보도

: 오픈AI 엔지니어들이 이달 초 새 최적화 기법을 통해 기존 모델 실행 비용, 즉 추론 비용을 절반 이하로 줄일 방법 내부 공유

: 해당 기법을 챗GPT에 적용했을 때 필요한 엔비디아 GPU 수는 한때 수백 개 수준까지 감소. 다만 이 사용자군은 사용량 제한이 있어 전체 트래픽 비중은 크지 않을 가능성

: 구체적 최적화 방식은 공개되지 않았으나 양자화, KV 캐싱, 배치 처리, 저전력 모델 또는 모델 일부로의 쿼리 라우팅 등이 포함됐을 가능성

: 이번 최적화 효과는 올해 후반 오픈AI가 더 큰 파라미터 규모 모델을 개발할 경우 축소 가능. 대형 모델은 일반적으로 실행 비용이 높기 때문

: 앤스로픽은 이런 효율화 기법을 “컴퓨트 멀티플라이어”라고 부름. 다리오 아모데이는 2023년 중반부터 해당 개념을 언급하며 경쟁사가 복제할 경우 우위가 줄어들 수 있다고 설명

: 추론 최적화는 AI 기업들이 충분한 서버와 GPU를 확보하기 어려운 상황에서의 핵심 과제. 데이터센터 계약을 맺어도 실제 가동까지 수개월 또는 수년이 걸릴 수 있음

: 오픈AI는 브로드컴과 함께 모델 실행에 특화된 자체 칩도 준비 중. 엔비디아 칩 대비 낮은 비용으로 추론 비용을 추가 절감하려는 목적

: 비용 절감분은 고객 혜택으로 이어질 수 있음. 팻GPT 구독자의 질의 한도를 늘리거나 API 모델 가격을 낮추는 방식 가능

: 가격 인하는 오픈AI가 비용 효율적인 모델 제공업체라는 평판을 강화하는 데도 도움. 특히 앤스로픽은 최근 높은 모델 비용으로 일부 비판을 받고 있음

: 반대로 오픈AI는 절감분을 매출총이익률 개선에 활용 가능. 1분기 GPM은 39%로 1년 전 33%에서 개선됐지만 연말 목표 52%에는 미달. 목표를 달성하려면 남은 기간 평균 56% 수준 마진 필요
