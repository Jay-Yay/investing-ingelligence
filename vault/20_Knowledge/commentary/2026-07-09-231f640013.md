## 원문
Samsung_Global_AI_SW (@Samsung_Global_AI_SW) — 2026-07-09T14:10:54+00:00

메타, Muse Spark 1.1 공개

: 에이전틱 작업, 코딩, 멀티모달 이해, 컴퓨터 사용에 특화된 최신 모델 Muse Spark 1.1 공개

: 메타의 첫 유료 개발자용 AI 모델로, 새로운 Meta Model API 공개 프리뷰를 통해 제공

: 신규 Meta Model API 계정에는 테스트, 출력 비교, 프로토타입 통합을 위한 20달러 무료 크레딧 제공. 종량제 가격은 인풋 $1.25 및 아웃풋 $4.25/백만달러

: 100만 토큰 컨텍스트 윈도우와 능동적 컨텍스트 관리를 지원하며, 장시간 실행되는 에이전틱 작업에서 강점

: 여러 에이전틱 평가에서 GPT-5.5 및 Opus 4.8에 필적하며, 일부 벤치마크에서는 최고 모델들을 앞선다고 주장

: 저커버그는 이번 모델이 구글 Gemini 계열 도구보다 우수한 성능을 보인다고 언급

: 메인 에이전트로서 맥락 수집, 계획 수립, 병렬 서브에이전트 실행 위임이 가능하고, 서브에이전트로서는 주어진 역할 수행과 에스컬레이션 판단 수행

: 컴퓨터 사용 측면에서는 데스크톱, 브라우저, 모바일 인터페이스를 조작할 수 있으며, 자동화가 빠를 때는 스크립트를 작성하고 직접 조작이 단순할 때는 클릭하는 방식으로 작업 수행

: 코딩 성능도 대폭 개선. 대규모 복잡한 코드베이스에서 버그 진단, 기능 구현, 코드 마이그레이션 등을 수행할 수 있고, 인기 있는 에이전틱 코딩 환경에도 최적화

: 멀티모달 측면에서는 이미지, 비디오, 오디오, PDF 등을 이해하고, 시각 정보를 코드 아티팩트로 변환하거나 실제 브라우저 작업과 결합하는 워크플로에 강점

: 초기 파트너로 Replit, Box, Cline 등이 참여. 메타는 낮은 비용의 프리미엄 에이전틱, 코딩, 멀티모달 모델을 API로 제공하는 전략 강조
