 ※ 본 건 금융위원회(금융감독원)에 제출하는 주요경영사항 신고는 증권거래법 제186조, 동법 시행령 제83조 및 유가증권의발행및공시등에관한규정 제69조에 의한 『법정공시사항』으로 그 내용에 허위, 중요사실의 누락이 있을 경우 증권거래법 제206조의11, 제207조의3에 의거 과징금 부과, 형사처벌 등 제재를 받을 수 있습니다. 
 기타 주요경영사항 

1. 제출사유
 
 (주)하이닉스반도체(이하, 당사), 프로모스社(ProMOS Technologies Inc., 대만)와 포괄적 제휴 협력 계약 체결 
 

2. 주요내용

| (1) 제휴상대방 | 프로모스社 | (국적) | 대만 |
| --- | --- | --- | --- |
| (2) 계약상의 주요내용 | 제휴 기술 | 당사의 50나노급 DRAM 공정기술 | |
| (2) 계약상의 주요내용 | 제휴 내용 | 당사의 50나노급 DRAM 공정기술에 대한 라이선스 허여 및 프로모스社 300mm 생산제품의 당사 파운드리 확대 | |
| (3) 제휴 이유 | 당사의 기술력과 프로모스社의 300mm 웨이퍼 가공 경험을 바탕으로 상호 경쟁력 강화 | | |
| (4) 기대 효과 | | -. 50나노급 300mm웨이퍼 가공 제품에 대한 안정적인 생산능력 확보-. 사용권 허여를 통한 기술료 수입 -. 프로모스와의 안정적 제휴협력기반 구축 | |

3. 결정(발생)일자
 
 2008년 5월 8일 
 

4. 기타 투자판단에 참고할 사항
 
 ※ 상기 3. 결정(발생)일자는 계약체결일임.※ 상기 계약과 더불어, 지분투자에 대한 LOI(Letter of Intent)를 별도로 체결함(당사 또는 당사가 지정하는 재무투자가와 연합하여 프로모스社의 일정 지분을 매입하고자 하는 투자 의향 제시)※ 관련공시일자 : 2003년 12월 19일, 2005년 1월 13일
