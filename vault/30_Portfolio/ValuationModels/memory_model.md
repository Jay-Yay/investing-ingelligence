## 2. 내재가치 모델 — "남은 피크 분기 수" 역산

### 2.1 왜 PER을 쓰면 안 되는가

현재 PER은 **삼성전자 6.0~7.2배 / SK하이닉스 3.3~4.6배**다. 얼핏 극단적 저평가로 보이지만,
**메모리에서 PER은 사이클 피크에서 최저가 되고 바닥에서 최고가 된다**(분모 E가 요동치기
때문). 즉 지금의 낮은 PER은 저평가 신호가 아니라 **피크 신호**로 읽어야 한다.

반대로 PBR은 왜곡이 덜하다. 현재:

| | 시가총액 | 자본총계 | **PBR** | 현재 ROE(연환산) | PBR이 함의하는 지속 ROE* |
| --- | ---: | ---: | ---: | ---: | ---: |
| 삼성전자 | ₩1,711.0조 (보통주 1,555.1 + 우선주 155.9) | ₩579.3조 | **2.95x** | 41.0% | 23.7% |
| SK하이닉스 | ₩1,233.0조 | ₩262.7조 | **4.69x** | 102.2% | 35.9% |

*\* P/B = (ROE−g)/(r−g), r=10%·g=3% 가정. 이 가정은 임의값이므로 절대 수준보다 두 종목
비교용으로만 쓴다.*

시장은 이미 현재 ROE(41%·102%)가 지속 불가능하다고 보고 훨씬 낮은 지속 ROE를 반영 중이다.
**따라서 "PBR이 높다"는 것만으로 고평가라 단정할 수 없다** — 피크 이익이 계속 자본으로
쌓이면 PBR은 저절로 내려가기 때문이다. 그래서 진짜 질문은 하나로 압축된다:

> **이 피크가 앞으로 몇 분기 더 가는가?**

### 2.2 모델

```
N분기 후 자본 = 현재 자본총계 + (분기 영업이익 × 0.78) × N
적정 시가총액  = N분기 후 자본 × 정상 PBR
```

## 4. Devil's Advocate

**Bull**: PER이 3~7배다. 자본이 분기마다 ₩47~70조씩 쌓이고 있어 시간이 지날수록 PBR이
자동으로 내려간다. AI 서버 수요는 과거 PC/모바일 사이클과 달리 구조적이며, HBM은
기술 장벽이 높아 공급이 쉽게 따라오지 못한다 — 이번 사이클은 과거보다 길 수 있다.

**Bear**:
1. **영업이익률 52%·76%, 매출총이익률 83%는 평균회귀의 대상이지 새로운 정상이 아니다.**
   이 마진은 공급 부족의 산물이며, 3번(CAPEX)이 반응하는 순간 되돌아온다. 그리고
   반도체에서 공급은 항상 반응했다.
2. **이 모델은 "피크가 끝나지 않는다"에 가장 취약하다.** 표의 분자(분기 자본증가)는
   피크 이익을 그대로 연장한 값이라, 사이클이 꺾이면 자본 증가가 멈추는 정도가 아니라
   **감액·감산으로 자본이 줄 수도 있다.** 표의 "추가 0분기" 행(삼전 PBR 2.0x
   ₩180,121 / 하이닉스 ₩737,179)이 하방 시나리오이며, 현재가 대비 각각 **−32% / −57%**다.
3. **SK하이닉스 순이익의 절반 이상이 영업 외 금융수익(₩65.9조)이다.** 내역 미확인 상태로
   이 이익을 반복 가능하다고 가정하면 밸류에이션을 크게 왜곡한다. 보수 기준으로 보면
   SK하이닉스는 삼성전자보다 뚜렷하게 비싸다.
4. **두 종목은 사실상 같은 베팅이다.** 렌즈가 "사이클 타이밍"인 이상 분산 효과가 거의
   없다. 게다가 6번(AI 서버 수요)을 통해 **NBIS·BE와도 연결**돼 있어, 포트폴리오
   7종목 중 4종목이 같은 AI 자본지출 사이클에 노출돼 있다.

**판단**: 이 사이클이 언제 끝나는지는 알 수 없다 — 그것이 이 모델의 결론이자 한계다.
확실한 것은 **(a) 현재 마진이 역사적 극단이고, (b) 삼성전자 현재가는 "1년 더 + PBR 2배"라는
비교적 온건한 전제 위에 있는 반면 SK하이닉스는 "2년 더 + PBR 2배"를 요구하며,
(c) 두 종목의 기존 target_price는 4~6년 연속 피크를 전제해 근거가 없다**는 것이다.
운용상 함의는 명확하다 — **이 포지션의 관리는 밸류에이션이 아니라 1번(계약가격) 감시로
한다.** 가격이 꺾이는 첫 신호에서 축소하는 것이, 저평가 논리로 버티는 것보다 이 업종에서는
언제나 나았다.
