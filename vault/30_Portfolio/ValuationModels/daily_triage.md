---

## 판정 절차

```
뉴스
 │
 ├─ ① 해당 종목 모델 문서의 10대 요소 중 하나에 매핑되나?
 │      └─ 아니오 → 노이즈. 반응하지 않는다.
 │
 ├─ ② 그 요소의 "숫자"가 실제로 바뀌었나?
 │      └─ 아니오(어조·전망·목표가·논평만) → 관찰. 로그만.
 │
 └─ ③ 숫자가 바뀜 → 역산 전제가 얼마나 이동하나? → 판정 임계선과 대조 → 행동
```

**핵심 원칙**: 어조는 입력값이 아니다. 목표주가 조정, "사상 최대 실적", "AI 버블",
"수혜 기대"는 전부 노이즈다.
