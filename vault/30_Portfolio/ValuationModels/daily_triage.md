## 판정 절차

```
뉴스
 │
 ├─ ① 아래 20개 요소 중 하나에 매핑되나?
 │      └─ 아니오 → 노이즈. 기록도 반응도 하지 않는다.
 │
 ├─ ② 매핑됨. 그 요소의 "숫자"가 실제로 바뀌었나?
 │      └─ 아니오(어조·전망·논평만) → 관찰. 로그만 남긴다.
 │
 └─ ③ 숫자가 바뀜 → 역산 전제가 얼마나 이동하나?
        NBIS: 반영 전환율(현재 12.1%)이 어디로?
        BE  : 필요 제품 백로그(현재 $14–21B 요구)가 어디로?
              └─ 판정 임계선과 대조 → 행동
```

**핵심 원칙**: 어조는 입력값이 아니다. 목표주가·"AI 버블"·"수혜 기대"는 전부 노이즈다.

## 두 종목 동시 판정이 필요한 경우 ⚠️

BE의 대형 고객 중 하나가 NBIS다([2026-07-14 $1.7B 공급계약](https://robinhood.com/us/en/stocks/BE/)).
따라서 아래 뉴스는 **한 종목이 아니라 두 종목 모두**에 매핑해야 한다:

- **AI 데이터센터 capex 사이클 관련 뉴스** → NBIS 9번 + BE 2번/8번 동시
- **NBIS의 자금조달 곤란·capex 축소** → NBIS 6번 + **BE 2번(수주 취소 위험)** 동시
- **금리 급등** → NBIS 10번 + BE 10번 동시

포지션 사이징에서 두 종목을 독립된 2개가 아니라 **사실상 1.5개 포지션**으로 취급한다.
현재 constraints는 `max_single_position_weight: 0.60` / `max_sector_weight: 0.60`이지만,
이 상관관계는 섹터 분류(AI Infrastructure vs Energy)로는 잡히지 않는다.
