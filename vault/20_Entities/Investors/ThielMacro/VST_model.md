## 2. 내재가치 모델 — "FCF 수익률" 역산

### 2.1 구조

순부채를 검증하지 못했으므로 EV 기반 배수 대신 **시가총액 대비 FCF 수익률**을 쓴다.
회사가 직접 가이던스로 제시한 숫자라 임의 가정이 들어가지 않는다.

```
적정 시가총액 = 2026 FCF(성장투자 전) ÷ 목표 FCF 수익률
```

### 2.2 민감도 (FCF 중간값 $4.325B, 335,635,195주 기준)

| 목표 FCF 수익률 | 적정 시가총액 | 환산 주가 | 현재가 대비 |
| ---: | ---: | ---: | ---: |
| 6% | $72.1B | $214.77 | +53% |
| 7% | $61.8B | $184.09 | +31% |
| 8% | $54.1B | $161.08 | +15% |
| **9.2% (현재)** | **$47.1B** | **$140.21** | — |
| 10% | $43.2B | $128.86 | −8% |
| 11% | $39.3B | $117.15 | −16% |

**해석**: 현재가는 FCF 수익률 **9.2%**를 반영한다. 계약이 대부분 장기 PPA로 고정된
발전사업자라면 6~8%가 통상 범위이므로 그 기준으로는 저평가로 보이지만, **PPA 비중이
전체 발전량의 얼마인지 확인하지 못했다** — 잔여 물량이 도매가에 노출돼 있을수록
높은 요구수익률(=낮은 배수)이 정당하다.

### 2.3 판정 임계선

| 상태 | 해석 |
| --- | --- |
| 신규 데이터센터 PPA 체결 (MW·기간 명시) | 계약 비중 상승 → 요구 FCF 수익률 하락 정당화 → **긍정** |
| Comanche Peak 가동 일정 지연 | 1번 계약 이행 리스크 → **부정** |
| PJM 용량경매 가격 급락 | 4번. EBITDA 직접 훼손 → **부정** |
| 규제당국의 데이터센터 부하 제한 결정 | 6번. 테마 자체가 막힘 → **부정** |

## 3. 뉴스 판정 규칙

| 뉴스 | 판정 |
| --- | --- |
| 신규 PPA 체결, **MW·기간 명시** | **행동(강세)** — 1번의 정량 확인 |
| 데이터센터 협력 "논의·MOU" | **관찰** — 계약이 아니면 EBITDA에 안 들어옴 |

| 원전 계획외 정지 | **행동(약세)** — 3번 |
| 전력 도매가 급등락 | **관찰 → 계약 비중 확인 후 판정** — 계약 물량이 많을수록 영향이 작다 |

## 4. Devil's Advocate

**Bull**: AWS·Meta와 맺은 원자력 PPA는 **탄소배출 없는 기저부하**라는, 대체 불가능한
상품을 장기 고정가로 판 것이다. 규제 유틸과 달리 이익 상한이 없고, 신규 원전 건설이
사실상 불가능한 상황에서 기존 원전 자산의 희소가치는 계속 오른다. FCF 수익률 9.2%는
이런 계약 자산 치고 높다.

**Bear**:
1. **PBR 8.58x는 유틸 4사(2.09~2.31x)의 4배다.** 같은 "AI 전력" 테마인데 밸류에이션
   방식과 하방 방어력이 전혀 다르다 — 규제라는 이익 하한이 없으므로 도매가가 무너지면
   막을 것이 없다.
2. **6/30 이후 −11.6%로 8종목 중 가장 크게 빠졌다.** 테마 전체가 조정받을 때 머천트가
   가장 먼저·가장 크게 반응한다는 것이 실제로 확인된 셈이다.
3. **계약 비중을 확인하지 못했다.** 3,800MW PPA가 인상적이지만 총 발전용량 대비
   몇 %인지 모르면 2번(도매가) 노출도를 알 수 없고, 따라서 9.2% FCF 수익률이 싼지
   비싼지도 판정 불가다. **이 모델의 가장 큰 공백.**
4. **Comanche Peak 가동이 2027년 말이다.** 현재 밸류에이션의 상당 부분이 아직 가동되지
   않은 자산에 걸려 있고, 그 사이 6번(규제)이 개입할 시간이 충분히 있다.

**판단**: 규제 유틸 4사가 "AI 전력"의 방어적 표현이라면 VST는 **공격적 표현**이다.
내 보유 BE(Bloom Energy)와 성격이 가장 가깝다 — 둘 다 규제 보호 없이 데이터센터
계약에 이익이 걸려 있고, 계약 발표에 주가가 크게 반응한다. **BE를 판단할 때
"같은 뉴스에 VST가 어떻게 반응했는가"를 참조군으로 쓰면 유용하다.**
