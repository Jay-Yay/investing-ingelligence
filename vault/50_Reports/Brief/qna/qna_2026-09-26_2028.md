# 질문

> 지금 여기서 codex 로그인 변경하니깐, chatgpt desktop app에서 로그아웃이 되었어. 혹시 연결되어 있나? 나는 지금 terminal에서는 개인 계정, desktop app에서는 회사 계정 사용하고 싶어.

# 답변

가능하다. 다만 ChatGPT 데스크톱 앱 안의 Codex 화면은 앱 전체와 같은 로그인 계정을 사용하므로, 그 화면에서 계정을 바꾸면 데스크톱 앱 전체 계정도 바뀐다. 반면 터미널의 Codex CLI는 별도 인증 저장소를 지정해 개인 계정으로 분리할 수 있다.

OpenAI 공식 문서상 Codex CLI와 IDE 확장은 같은 캐시된 로그인 정보를 공유한다. 데스크톱 앱과 CLI가 반드시 같은 캐시를 공유한다고 명시되어 있지는 않다. 따라서 터미널에서 `codex login`만 실행했는데 데스크톱 앱까지 로그아웃됐다면, 브라우저 인증 과정에서 기존 ChatGPT 계정을 로그아웃했거나 데스크톱 앱의 Codex 로그인 자체를 변경했을 가능성이 있다. Codex CLI 인증은 기본적으로 `~/.codex/auth.json` 또는 운영체제 자격 증명 저장소에 보관된다. [`CODEX_HOME`과 `cli_auth_credentials_store`를 사용하면 별도 파일 저장소로 격리할 수 있다](https://learn.chatgpt.com/docs/auth#credential-storage).

터미널 전용 개인 계정을 다음처럼 분리한다. 아래 함수를 `~/.zshrc`에 추가한다.

```zsh
codex-personal() {
  CODEX_HOME="$HOME/.codex-personal" command codex \
    -c 'cli_auth_credentials_store="file"' "$@"
}
```

새 터미널을 연 뒤 개인 계정으로 로그인한다.

```zsh
codex-personal login
codex-personal login status
```

이후 개인 계정용 터미널 작업은 항상 `codex-personal`로 시작한다. 일반 `codex` 명령과 데스크톱 앱은 기존 기본 저장소를 계속 사용할 수 있다. 로그인 브라우저가 회사 계정으로 열리면 회사 계정을 로그아웃하지 말고, 개인용 브라우저 프로필이나 시크릿 창에서 개인 계정을 선택한다. 필요하면 [`codex login --device-auth` 방식도 사용할 수 있다](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta).

데스크톱 앱에서는 회사 계정으로 다시 로그인한다. 이후 `codex-personal logout`은 격리된 개인 CLI 저장소만 대상으로 하므로, 기본 데스크톱 로그인과 충돌할 가능성을 줄인다.

API 키를 개인 터미널에 쓰는 방법도 있지만, 이는 ChatGPT 구독 사용량이 아니라 OpenAI Platform의 종량제 과금이며 일부 ChatGPT 연동 기능이 제한될 수 있다. 개인 ChatGPT 구독을 쓰려면 위의 별도 `CODEX_HOME` 방식이 더 적합하다. [OpenAI 인증 문서](https://learn.chatgpt.com/docs/auth#sign-in-with-an-api-key)
