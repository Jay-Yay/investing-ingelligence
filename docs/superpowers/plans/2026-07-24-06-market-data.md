# Market Data Provider Implementation Plan

**Goal:** Build the `MarketDataProvider` protocol plus adapters for US equities (Yahoo Finance)
and crypto (CoinGecko), producing `Quote`/`PriceBar` models the later portfolio-calculations
phase (08) will consume. Independent of every collector built so far — no `Collector` protocol
involvement, no vault/index writes.

**Scope decision (yfinance adapter implementation):** The design doc names the file
`yfinance_adapter.py` after the *data source* (Yahoo Finance), not a mandate to depend on the
`yfinance` PyPI package. That package pulls in a heavy transitive footprint (pandas, numpy,
requests, multitasking, curl_cffi, …) and — critically — does its own HTTP internally, which
cannot be mocked with `respx` the way every other external call in this project is tested. This
phase instead hand-rolls a small `httpx`-based client against Yahoo's public chart endpoint
(`query1.finance.yahoo.com/v8/finance/chart/{symbol}`), consistent with every other adapter built
so far (SEC, DART, Naver, Telegram) and fully respx-testable. **Known operational risk (not
solved here, stated honestly):** Yahoo has, at times, required a cookie+crumb handshake for this
endpoint to defend against bot traffic; this phase does not implement that handshake. If it
proves necessary in production, that's a follow-up, not a silent gap — flagged here explicitly.

**Scope decision (CoinGecko coin id):** Same precedent as DART's `corp_code` and SEC's `cik` —
no ticker→coin-id resolution service. The caller supplies CoinGecko's own `coin_id` (e.g.
`"bitcoin"`) directly; this phase does not build a symbol-mapping cache.

**Scope decision (CoinGecko OHLC volume):** CoinGecko's `/coins/{id}/ohlc` endpoint (used for
`PriceBar` history) does not include volume — only `/market_chart` does, as a separate,
differently-shaped series. This phase reports `volume=0.0` for crypto price bars rather than
issuing a second API call to stitch volume in; a documented gap, not an oversight.

## Global constraints

Inherited from phases 01-05: no live network calls in tests (`respx` mocks all `httpx` traffic);
no placeholders/TODOs.

## Task breakdown

### Task 1: `MarketDataProvider` protocol + `Quote`/`PriceBar` models

**Files:** create `investor_intel/market_data/__init__.py` (empty),
`investor_intel/market_data/provider.py`; test `tests/test_market_data_provider.py`.

**Interfaces:** `Quote(BaseModel)`: `symbol: str, price: float, currency: str, as_of: datetime`
(tz-aware). `PriceBar(BaseModel)`: `date: date, open: float, high: float, low: float, close:
float, volume: float`. `MarketDataProvider(Protocol)`: `get_quote(symbol: str) -> Quote`,
`get_price_history(symbol: str, days: int) -> list[PriceBar]`.

- [ ] Write failing tests (model validation: tz-aware `as_of` required, same pattern as
      `SourceDocument`'s existing timezone validator), implement, verify pass
- [ ] Commit: `feat: add MarketDataProvider protocol and Quote/PriceBar models`

### Task 2: Yahoo Finance adapter

**Files:** modify `investor_intel/collectors/http_client.py` (add `.get_json(url) -> dict`,
mirroring `SECClient`/`DartClient` — the third consumer needing JSON, not just text); create
`investor_intel/market_data/yfinance_adapter.py`; test `tests/test_yfinance_adapter.py`.

**Interfaces:** `YahooFinanceError(Exception)`. `YahooFinanceAdapter(client: SimpleHttpClient)`
with `.get_quote(symbol) -> Quote` (reads `chart.result[0].meta.{regularMarketPrice,currency,
regularMarketTime}`), `.get_price_history(symbol, days) -> list[PriceBar]` (uses explicit
`period1`/`period2` UNIX-timestamp params computed from `days`, not the `range` string param,
for precise control — `interval=1d`). A `chart.error` non-null response (e.g. delisted/invalid
symbol) raises `YahooFinanceError`.

- [ ] Write failing tests (quote parses meta fields; price history maps timestamp+OHLCV arrays
      to `PriceBar`s; a `chart.error` response raises), implement, verify pass
- [ ] Commit: `feat: add Yahoo Finance chart API market data adapter`

### Task 3: CoinGecko adapter

**Files:** create `investor_intel/market_data/coingecko_adapter.py`; test
`tests/test_coingecko_adapter.py`.

**Interfaces:** `CoinGeckoError(Exception)`. `CoinGeckoAdapter(client: SimpleHttpClient,
vs_currency: str = "usd")` with `.get_quote(coin_id) -> Quote` (`/simple/price` endpoint, `as_of`
set to fetch time since the endpoint doesn't return a timestamp), `.get_price_history(coin_id,
days) -> list[PriceBar]` (`/coins/{id}/ohlc` endpoint, `volume=0.0` per the scope decision above).
Empty/error response body raises `CoinGeckoError`.

- [ ] Write failing tests (quote parses simple/price response; OHLC maps to `PriceBar`s with
      `volume=0.0`; empty response raises), implement, verify pass
- [ ] Commit: `feat: add CoinGecko market data adapter`

## Self-review notes

- **Reuse over duplication:** both adapters take a `SimpleHttpClient` (phase 05) rather than each
  rolling their own retry/rate-limit logic a fourth and fifth time.
- **Deferred, not skipped:** Yahoo cookie/crumb handling, CoinGecko symbol→coin_id resolution,
  and CoinGecko volume-in-OHLC are named out-of-scope items with stated reasons.
