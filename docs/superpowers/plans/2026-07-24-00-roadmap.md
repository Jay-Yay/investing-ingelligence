# Investor Intelligence — Plan Roadmap

Design spec: `docs/superpowers/specs/2026-07-24-investor-intelligence-design.md`

This project spans independent subsystems (per the design doc §2). Each gets
its own bite-sized implementation plan, written just before that phase starts
so it reflects the actual state of the code at that time. Plans are executed
in order; each produces working, tested software before the next begins.

| # | Plan file | Subsystem | Status |
|---|---|---|---|

| 02 | `2026-07-24-02-sec-13f-collector.md` | SEC EDGAR 13F XML collector (Duquesne, Situational Awareness LP) | merged to main |
| 03 | `2026-07-24-03-sec-filings-collector.md` | Company filings collector (10-K/10-Q/8-K/20-F/6-K) for NBIS/BE/RDDT | merged to main |
| 04 | `2026-07-24-04-dart-collector.md` | OpenDART collector | merged to main |
| 05 | `2026-07-24-05-naver-telegram-collectors.md` | Naver blog + Telegram collectors | merged to main |

merged, but will be executed sequentially here for simpler review.
